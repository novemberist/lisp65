# lisp65 1.5.0 Release Notes

Release date: pending publication

lisp65 1.5.0 makes the Workbench visibly alive while it starts, makes ordinary
REPL exploration immediate, and delivers the two long-awaited development
tools: reversible function tracing and positional structures. The visible
banner is `WORKBENCH 1.5.0`.

## A Workbench that explains its waits

Cold start now reports its current phase:

```text
LISP65: STAGING MEDIA
LISP65: BUILDING HEAP
LISP65: LOADING LIBRARIES n
```

The library ordinal disappears before the banner and prompt take ownership of
the screen. `require` likewise echoes visible progress while it performs a
durable package installation.

On the accepted physical MEGA65, released v1.4.0 took **31 seconds** from the
physical reset to `lisp65>`; the v1.5.0 candidate took **36 seconds** under the
same owner-timed choreography. The five-second increase accompanies the
hardware-proved MAP CPU transport and safety closure that removed trust in DMA
completion from the bulk library-reading path. Halt #1 explicitly accepted
that measured cost. A pre-published boot snapshot remains a post-v1.5
optimization candidate rather than release freight.

## Immediate exploration, durable definitions

Non-persistent expressions now use the direct REPL path: nested arithmetic,
list access, structure accessors and ordinary published calls begin without the
former transient compile/append/rollback ceremony. The hardware release smoke
measured zero frames inside representative list-read, list-write, string and
published-call bodies.

Forms that change durable state — including `setq`, `defun` and macros — still
take a visible moment, approximately 1.2 seconds for an ordinary form on the
accepted device. That work is what makes definitions survive the product's
publication and rollback contracts; v1.5 does not weaken those contracts to
hide the cost.

## Reversible tracing

`(require 'inspect)` now provides `trace` and `untrace` alongside `who-calls`:

```lisp
(defun probe (x) (+ x 1))
(trace probe)
(probe 4)       ; prints ordered trace-enter/trace-exit records, returns 5
(untrace probe)
(probe 4)       ; returns 5 without trace output
```

The private function-cell ABI captures the exact original BCODE value. Wrapper
publication is transactional, and `untrace` restores that exact value. The
hardware session proved traced execution, untrace and the restored call in
sequence.

## Positional structures

`(require 'defstruct)` delivers positional, option-free tagged-list records:

```lisp
(defstruct point x y)
(setq p (make-point 3 4))
(point-p p)          ; => t
(point-x p)          ; => 3
(point-y p)          ; => 4
(point-set-y p 9)    ; destructive setter
(point-with-y p 4)   ; functional copy with one changed slot
(copy-point p)
```

The defining macro publishes its constructor, predicate, copier, accessors,
setters and functional updaters durably. It is substantially heavier than an
ordinary definition and therefore remains a visibly long operation. The
terminal-return shadow guard protects the publication edge; the accepted
hardware run produced `(point 3 4)` with all four mismatch records empty and
no restoration.

## Input and compiler correctness

- Top-level macros are expanded before the compiler classifies the resulting
  form. A macro that expands into `defun`, `defmacro` or another defining form
  therefore follows the correct durable path.
- Shift-Space PETSCII `$A0` is normalized to ordinary space at the interactive
  input boundary. This fixes the natural `) (` typing sequence where Shift can
  remain held between two parentheses while the screen still appears to show a
  normal space. Non-displayable controls are rejected visibly.
- Multiple forms on one line are evaluated left to right. If trailing input
  later has a reader error, preceding forms have already run; the User Guide
  calls this out explicitly.

## Transport safety

The bulk library path and all nine mutable content readers now use the
hardware-proved MAP CPU reader. They no longer depend on a DMA completion bit
or on a second unverified DMA probe for their reference bytes. Immutable boot
spans retain delivery-bound CRC verification. The linked-image gate reports
zero content-consuming DMA readers outside those CRC-covered immutable spans.

## Known limitations

The maintained [Known Issues and Retired Exceptions](../known-issues.md) holds
the complete current boundary. In particular, enter the Freezer only while the
REPL is idle; fail-closed stops still do not print their cause; `defstruct` is
positional and option-free; the name arena is finite; standalone Ship RUN/STOP
still lacks an independent `$91` verification; and the system remains a small
Common Lisp-inspired dialect rather than ANSI Common Lisp.

## Claim boundary

v1.5.0 claims the exact product/library pair and hardware rows above. It does
not claim active-persistence Freezer safety, line-atomic REPL input, instant
durable publication, the post-release boot snapshot, arbitrary live-session
shipping, or any parked parity feature.
