# WORKBENCH 2.2.0


This is a product release. The qualified product still displays
`WORKBENCH 2.0.0` in its boot banner; the package version is 2.2.0.

## Included

- R2 soft call frames: the bound device test returns at depths 12, 13 and
  16; depth 17 is refused with a stack-overflow error and a live prompt.
  These are results for the documented test, not a general safe nesting
  depth for arbitrary programs. Native recursive helpers such as the
  printer remain outside this claim.
- Native-prompt line wrapping, including deletion across the wrap boundary
  and the Backspace repair that removes inverse cursor rectangles.
- The physical pound key as quasiquote outside strings. The earlier
  accepted keyboard row produced `(1 2)` from `£(1 ,(+ 1 1))`; it was not
  re-run in the final repair-world session.
- A, Diet 1 and the capacity/library composition, including the moved
  E000 owners and the code-arena owner bound.
- Five optional packages on the system disk: `buffer`, `place`,
  `string-extra` (not `strings-extra`), `inspect` and `defstruct`.
  Load them manually with symbol-form `require`, for example
  `(require 'place)`. IDE, IDEX and M65D retain their `load-lib` path.
- Descriptor-based retirement cleanup and iterative direct argument
  evaluation. The 40-argument device form now returns the existing type
  error and a live prompt instead of halting; a fresh `(+ 4 5)` returns 9.
  The existing 12-argument call/apply bound is not increased.
- The inherited F011 buffered-read repair and the PCRel16 class fix.

## Measured boundaries

Ordinary text reserve is 2,359 bytes against a floor of 32; Capture reserve
is 458 against 57. Final native responsiveness ratios are 0.999733 and
0.999818; VM-step ratios are 1.000 and 1.000. The GC comparison is within
its bound. These are host/emulator measurements, not a new typing-feel
or wall-clock claim.

The pure five-package host loading stop has 32 free symbols, 384 free name
bytes and 8,576 contiguous user-code bytes. The longer final device session
has 19 / 273 / 8,435 after its test definitions, generated structure names
and one recorded typing correction. No estimated allocations are subtracted
from that device measurement. These independent resources cannot be assumed
to be exhaustible simultaneously.

The final device boot was variant B: at least 30 seconds powered off,
then Freezer mount and product start. No automatic-mount variant-A or new
boot-time measurement is claimed. The four native smokes returned
`0 2`, `0 (9 2)`, `0 98`, and `0 42`. The session ended with the approved
RAM stop and an owner reset to BASIC.

## Not included and remaining limitations

No Comfort, Comfort trampoline, general hardware-SP floor, Matcher/Blink,
or Tier-2 promotion is claimed. There is no `INIT.L65` on the selected
medium. Library loading from an INIT source remains unsupported because
of shared scratch; its repair, string-form `require` and default loading
are commissioned for the following release, not shipped here.

The compiler's measured self-compile peak exceeds the 16-frame product
capacity. Deep forms may be refused; printer recursion is a separate
remaining native-stack limitation. Read the Known Issues before use.

The card's full `check-source` completed with the explicitly tolerated
historical Carrier-SHA pin as its only failed target, not unconditional
Exit 0. The two independent release-chain reproductions now match PRG, ELF, profile,
D81 and all 16 media roles. The source projection includes the transitive
generated decoders and checks consumed include paths and SHAs before codegen.
The separate Before-Ship checklist reports the full `check-host` result;
no unconditional host-suite green is claimed here.
