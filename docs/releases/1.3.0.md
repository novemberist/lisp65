# lisp65 1.3.0 Release Notes

Release date: 2026-08-03

lisp65 1.3.0 is the first release centered on programs that leave the
Workbench. Its Ship Builder turns a small L65P-v1 project into a standalone,
bootable D81 containing the cold stager, evaluator-free runtime, required
library closure, compiled program and redistribution notice.

Four projects exercise the real Ship path: a minimal program, a `random` and
Q8.7 program, a long-running program, and an interactive program. On the
accepted MEGA65, the interactive disk waited, read `Ada` from the physical
keyboard and displayed `Hello, Ada!`.

## Input, timing and fixed-point arithmetic

The public base composition now includes:

- `read-line`, a bounded editable line reader with echo, DEL handling and a
  250-character limit;
- `key-event` for low-level polling or blocking key events;
- `wait` for interruptible raster-frame delays; and
- the signed Q8.7 family `q`, `q+`, `q-`, `q*`, `q/`, `int->q`, `q->int`
  and `q->string`.

The Q8.7 API was named `fx` in v1.2.4 and v1.2.5. Because v1.3.0 is the first
advertised release, the public spelling changes now, before compatibility
costs accumulate. Replace `fx` with `q`, `fx+` with `q+`, and likewise for the
remaining conversion and arithmetic names. The representation and rounding
rules are unchanged.

`(time form)`, `wait`, `random`, and `random-seed` require no library load.
`wait` admits 0 through 16,383 frames and remains abortable with RUN/STOP.

## Faster editor and complete reset staging

The Workbench editor no longer materializes the complete typed line for every
redisplay. On the accepted hardware workload, average typing cost fell from
about 78 to about 24 raster frames per key. A permanent allocation gate limits
the per-key cell cost.

The cold stager now writes the complete 50,816-byte Bank-5 reset domain,
including a cleared C2J journal, instead of staging only the C2D prefix. This
keeps RUN/STOP recovery from inheriting stale journal bytes. The release case
typed 30 characters, used RUN/STOP, and then evaluated `(+ 4 5)` to `9` in the
same live REPL.

Standalone runtimes also establish their own frame clock rather than
inheriting one. The boot gate uses the full 9-bit VIC raster sequence as its
independent oracle: all 312 starting phases demonstrate repeated frame
progress. The physical interactive sample proves the complete `wait` →
`read-line` → output path.

The visible Workbench banner is `WORKBENCH 1.3.0`.

## Language and documentation surface

The public reference now binds 90 delivered function names. It documents the
base string and character-code functions, compiler-lowered language forms,
the numeric character model, string traversal without the retired
`string->list`/`list->string` names, and the `read-line` →
`read-from-string` parsing pattern.

The shipped string surface includes `string-trim`, case conversion,
comparison, prefix/suffix tests, append and substring. The one-sided trim
pilot and the retired list converters are not advertised or packaged.

## Known issues

The maintained [Known Issues and Retired Exceptions](../known-issues.md)
contains the complete user-facing boundary. In particular:

- enter the Freezer only while the evaluator is idle;
- do not use interrupt-generating cartridges while lisp65 is running;
- preserve the exact workload if the intermittent post-GC out-of-memory
  symptom returns;
- if the editor stops accepting input near its first collection, use RUN/STOP
  and preserve the preceding session for a report;
- standalone Ship programs must not rely on a release claim for RUN/STOP; and
- `defstruct`, dynamic package freight, `gc`, `room`, `error`, and
  `restart-repl` are not delivered.

## Claim boundary

v1.3.0 claims the exact sealed C2-lite product, the four Ship samples and the
hardware results above. It does not claim arbitrary live-session shipping,
Freezer safety during an active persistent definition, interrupt-generating
cartridge support, a GC latency ceiling, `defstruct`, dependency-safe unload,
a general condition system, a tick callback, color-RAM scrolling, or C2-full
transport safety.
