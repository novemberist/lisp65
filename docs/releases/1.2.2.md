# lisp65 1.2.2 Release Notes

Release date: 2026-07-29

lisp65 1.2.2 fixes undefined-function diagnostics so that they report the
complete symbol name. In earlier 1.2 releases, the displayed name could be
truncated to a single character or padded with spaces, making errors in user
code unnecessarily difficult to identify.

There are no other product changes in this release. Dialect V2, the C2-lite
media model, and the supported hardware profile are unchanged from 1.2.1.

## Informative GC measurement

An additional G5 measurement compared 1,000 otherwise identical `boundp` and
`symbol-value` operations. The measured difference was **0 frames**, so one
2-byte symbol-value read costs less than one frame per 1,000 reads
(less than 20 microseconds per read at 50 Hz). Projected across the 480
symbol-value reads in a collection, this contributes less than half a frame to
the isolated 89-frame GC envelope.

This categorically excludes the Bank-5 symbol-value read path as the dominant
GC cost. The dominant term of that 89-frame envelope remains unattributed; no
GC optimization or GC latency ceiling is claimed by this release. The number
applies directly only to the measured 2-byte symbol-value transport, not to
bulk symbol-name reads or the one-byte C2D resolver primitive.

## Known issues

The maintained [Known Issues and Retired Exceptions](../known-issues.md)
contains the complete user-facing boundary. The shortened undefined-function
name issue is removed in 1.2.2. The remaining limitations are unchanged,
including:

- Freezer entry during an active persistent definition;
- interrupt-generating cartridges;
- the intermittent, unreproduced post-GC out-of-memory observation; and
- parked `defstruct` and dynamic-package freight.

## Claim boundary

v1.2.2 claims the exact sealed C2-lite product and the hardware results above.
It does not claim Freezer safety during an active persistent definition,
interrupt-generating cartridge support, a GC latency ceiling, a standalone
application builder, `defstruct`, dependency-safe unload, or a general
condition system.
