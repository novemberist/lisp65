# lisp65 2.0.1 Release Notes

Release date: 2026-09-03

lisp65 2.0.1 is a documentation-only correction. It reuses the complete
2.0.0 product artifact set byte-for-byte: the resident PRG, product D81, work
D81, library images, boot files and linked proof ELF do not change. The
on-device banner therefore remains `WORKBENCH 2.0.0`.

The corrected bundle brings the public documents onto the delivered surface:

- the guide, reference, issue register and indexes identify release 2.0.1 and
  the `lisp65-2.0.1` archive root;
- all 139 names in the host metadata population are documented, while a
  medium projection distinguishes the 127 delivered identities from the 12
  optional-library names that are not on the product D81;
- the Tier-1 domain change names the actual twenty-one public functions whose
  62 contract cells changed;
- error-code, arity, example, keymap, D5 and Capture counts are derived from
  their product authorities; and
- the generated keymap no longer describes the historical 1.1 fallback.

No product behavior or hardware claim changes. The 2.0.0 device acceptance
remains the authority: Capture crossed a forced collection with
`raw = seen = stored = taken = 138`, release-terminal D5 measured 107 free
symbol slots and 1,467 free name bytes, and the native prompt editor retained
the hardware-proven v1.9 input path.

The bundled-document Halt-B gate now checks the release identity, archive
root, public-name coverage, medium-aware absence claims, and all derived
counts before packaging. This closes the historical class that allowed the
2.0.0 product bundle to contain user documents from an older release world.
