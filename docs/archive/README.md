# Documentation Archive

This directory contains non-normative project history. It is retained for
provenance, debugging context, and archaeology—not as current product guidance.

## `pre-1.0/`

- `audits/` contains completed investigations, capacity reviews, and hardware
  findings.
- `handoffs/` contains superseded collaboration and reviewer handoff records.
- `planning/` contains plans, stop memos, and release paths completed or
  superseded before 1.0.0.
- `contracts/` contains the detailed machine-bound prose contracts used to
  produce 1.0.0; current authorities are mapped in
  [`../implementation-contracts.md`](../implementation-contracts.md).
- `designs/` contains implemented or superseded design proposals.
- `reference/` contains pre-1.0 research, language, hardware, and model notes.

The living append-only decision chronology remains at
[`../decision-log.md`](../decision-log.md); it is not an archive document.

Archive files may remain in their original language. Their commands, memory
figures, candidate hashes, and status statements may be obsolete. Use
[`../README.md`](../README.md) to find current documentation and consult sealed
receipts for exact historical evidence.
