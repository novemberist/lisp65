# C2.2 `require` identity-before-parser qualification

Status: **host-green; product-shaped Bank-2 candidate, no link or hardware**

Date: 2026-07-28

## Decision

The already-loaded path checks identity before opening or parsing `L65INDEX`.
It does not add a second loaded-library registry. A single non-authoritative
resolution cache is populated only after successful publication, a second
full world proof, and confirmation that the requested combined CRC is present
in current-generation persistent C2D.

A cache hit requires all of:

1. the same canonical library symbol;
2. the same non-NIL canonical L65I index lock;
3. byteequal generation, image/entry/resolution/root counts and transient
   watermark;
4. the same complete ordered persistent combined-CRC sequence.

Any mismatch falls through to the unchanged parser and full resolver. The
cache never decides failure and never marks a library loaded.

## Measurement

Five independent host samples used the compiled candidate and the same exact
Link-75 C2D/D81 model as Phase M1.

| Repeat lane | VM steps | Prim-67 reads | Disk reads | Loads |
|---|---:|---:|---:|---:|
| accepted baseline | 134,788 | 384 | 2 | 0 |
| identity-before-parser | 2,750 | 26 | 0 | 0 |
| reduction | **97.96%** | **93.23%** | 100% | unchanged |

Both hard 90% conditions pass. Bank-2 code grows from 13,835 to 14,297 bytes,
an exact **+462 B** against the 512-byte ceiling. No C or assembler source is
changed, so native/resident delta is **0 B**.

## Proof preservation

The slow route still proves L65I CRCs and uniqueness, C2D header/caps/layout,
static and active layout, transient fronts, dependency order, all six
capacity currencies, publication and post-publication identity. The fast
route reuses immutable proofs only while every legal mutable discriminator is
unchanged. Promotion additionally requires the permanent source/ELF no-writer
proof that no serialized top-level transition can mutate the reused immutable
fields without changing those checked discriminators.

Five negative directions force the slow route:

- a foreign persistent identity;
- a wrong generation;
- a wrong index lock;
- a stale/empty cache;
- a different library name.

The first three fail closed after the slow proof; the latter two resolve
normally. Each mutation executes the real L65I parser, not a simulated branch.
