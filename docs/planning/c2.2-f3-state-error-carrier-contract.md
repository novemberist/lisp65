# C2.2 F3 state/error carrier contract

Status: candidate for halt #2; no product link and no hardware claim.

F3 carries the already pinned `gc`, `room`, and `(error String)` surface
through the existing private Buffer-read carrier.  It does not introduce a
general private-service dispatcher.  Primitive 63 remains the only resident
facade and selectors 4, 5, and 6 execute in the already cold
`.lisp65_rt_buffer_read` slice.

`gc` performs exactly one synchronous collection and returns canonical `t`.
`room` takes one pre-allocation snapshot and returns a proper list in this
fixed order:

1. heap free and capacity;
2. symbol free and capacity;
3. name-pool free and capacity;
4. directory free and capacity.

All eight values must fit the signed 15-bit Fixnum domain.  The list is an
observer cost: its own cells are deliberately absent from the reported
snapshot.  The partial list remains rooted across every allocation and OOM is
fail-closed.

`error` accepts exactly one String.  Its selector validates `T_STR`, records
append-only error code 64 and sends the original object through the existing
status-plus-object abort seam.  L65E renders the exact bytes without
allocating, interning, or adding a resident/static user-message string.  The
normal three-star prefix remains owned by the existing top-level renderer;
the overlay emits only the supplied bytes.  Handlers, restarts, numeric user
codes and resumable continuations are outside this cut.

The three public functions must work through direct call, `funcall`, and
`apply`.  No selector becomes public, no primitive ID is added, and no state
cell or root is added.

## Capacity decision

F2 is the resident baseline: text 90 bytes free, `$E000` 151, fixed block 2,
ordinary BSS 137 and resident island 69.  F3 qualifies only if the single
product-shaped WPLTO preserves all five values exactly.  A resident debit of
even one byte parks the entire trio for halt #2; no wall, floor, anchor, or
reserve is renegotiated.  The cold caps remain 1,792 bytes for Buffer-read and
1,320 bytes for L65E.

No hardware result is claimed before the bundled S1 session.
