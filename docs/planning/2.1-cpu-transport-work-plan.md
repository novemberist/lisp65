# 2.1 work plan — CPU transport for the library load path

Status: **commissioned 2026-08-13 (owner)** on hardware-proven
ground: the MAP probe passed fully — Bank 5 and Attic are CPU-side
readable (256 reads each, `A5`) — while the ring measured ~6.5 s per
logical read with the final PC in `crc32_update+$29`.

## The one sentence

Move the library load path from DMA-plus-convergence to **MAP-based
CPU reads**: no submission, no completion signal, no convergence
proof, none of the 2,361,562 probe jobs — the F018B class disappears
at its root for this path, because there is no completion to distrust.

## Why this is the root fix, not a workaround

Every convergence verifier exists to compensate for a transport whose
completion signal cannot be trusted. A transport that has no
completion signal needs no compensation. The class rule stays
untouched and simply stops applying here: **no content-consuming read
trusts a completion signal — and a CPU read has none.**

## Scope

1. The library load path's reads (all 346,298) route through the
   MAP-based CPU reader proven by the probe; the DMA path and its
   verifiers remain for any site the probe does not cover, unchanged
   and still class-gated.
2. Per-read cost priced against the probe's measured CPU read cost;
   the honest expected LOADING LIBRARIES duration is a deliverable of
   this block (with the ring available to confirm it on device).
3. **Desk rider: attribute the `crc32_update` cost** — ~6.5 s per
   logical read implicates the verifier's CRC span, and the finding
   may matter for paths that stay on DMA. Priced, not guessed.
4. **Class A alongside:** the diagnostic medium's missing STAGING
   MEDIA prefix is a closure defect of the *diagnostic* producer —
   the closure-completeness clause extends to every medium builder,
   not only the product one, with its mutation.

## Bounds

House rules verbatim; host-first; one card under producer discipline;
then media, D1 and the D2–D5 session. Correctness walls: the
delivered content's CRC authentication stays, the journal/rollback
contracts stay, zero resident bytes.

## Call-seam pricing result — 2026-08-14

The three commissioned shapes are fully priced against the frozen shrink-card

1. The only selector-shaped existing seam is
   `c2_facade_runtime_overlay_exec` at `$B5EB`.  Preserving that ABI requires
