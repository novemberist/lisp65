# 1.3 work plan — the ship builder

Status: **commissioned 2026-07-31** (owner-confirmed sequence after the
balance review; the fail-closed attribution has reported).
Baseline: released v1.2.5, Link 83 unpromoted (editor freight parked),

## The one sentence

`(ship "program" :entry 'main)` produces a **standalone bootable D81** —
stager, redistributable runtime core, tree-shaken libraries, the user's
compiled program — so a lisp65 user can hand a disk to someone who has
never heard of lisp65. The standing product order finally lands: the
ship path precedes ecosystem breadth, and delivering it unlocks the
parity pilot for the block after.

## Ground rules

Unchanged: host-first, receipts with execution witnesses,
dependency-sharp first red, no inherited green, resident geometry
closed (ship tooling is host/media work — the product core it packs is
the sealed one). **New standing harness rule from the attribution,
binding on every session here: exact-result screenshot polling must
never enclose a persistently writing form; quiet execution,
postcondition reads only.**

## Phase S-A — Contract (paper)

A1. **Media/entry contract**: the ship-D81 layout (stager, runtime-core
    image, library set, user FASL, autoboot), the `(ship name :entry
    fn)` surface, error behavior for unresolvable entries, and what
    "redistributable" includes — named explicitly, since the shipped
    disk carries our runtime to third parties.
A2. **Closure rules**: which libraries ride (tree-shaken from the
    user program's requires), what never rides (diagnostics, probes),
    and the size model against a D81.
→ No halt; the contract binds S-B.

## Phase S-C2 — `read-line` (owner scope addition, 2026-07-31)

The owner's practicality test — "nobody ships a program that cannot read
text input" — adds one bounded freight item to this block:

C2-1. **`read-line`** in the base composition (the `random` pattern:
      host-first, Bank 2, zero resident). Composed on the existing
      `key-event`, `screen-size` and `screen-put-char` primitives: the Lisp
      routine owns a last-row viewport, performs echo and destructive DEL,
      RETURN terminates and returns a string; the length cap is named in the
      contract (the string arena is the bound). RUN/STOP behavior is stated
      (abort path, never coalesced). No native DEL seam or C screen-driver
      change is part of the product.
C2-1b. **`(wait frames)`** (owner request 2026-07-31), same card: block
      for the given number of raster frames on the calibrated `$FF83/$FF84`
      counter (the `(time)` base, 51.966 Hz), polling RUN/STOP so a wait
      is always abortable; overflow bound named like `(time)`'s. The
      shipped-program essential for pacing — animation and delays without
      the tick hook (`draw → wait → draw`). Trivial Bank-2 cost, zero
      resident.
C2-2. **`key-event`, `read-line` and `wait` enter the public surface**: the
      66-name reference grows, the surface-delivery parity gate binds
      them, and the user guide gains an input section (with `read-line`
      first and `key-event` as the low-level escape) plus `wait` beside
      `(time)` in the timing notes.
C2-3. **The fourth ship sample is interactive**: read a name, respond —
      the smallest honest proof that a shipped program can converse.
      It joins the sample fleet and the D1 boot rows.
C2-4. **Rename `fx` → the `q` family** (owner decision 2026-08-01,
      window: no users exist before the first advertised release, which
      is 1.3). Public surface becomes `q`, `q+`, `q-`, `q*`, `q/`,
      `int->q`, `q->int`, `q->string` — "Q-format" is the domain term
      for Q8.7 and collides with neither sound-effects nor Scheme's
      integer `fx` operations. Scope: the library source and carrier
      (riding this block's cycle anyway), the source/artifact gate and
      its case names, the surface-delivery parity binding, and the guide
      section (input/timing docs land as `q` from the start). The sealed
      1.2.4/1.2.5 releases stay untouched history; the v1.3.0 notes
      state the rename plainly. The sound-namespace collision rule
      becomes moot and is not carried.
→ The A2 allocation gate and equivalence lanes cover the new code; one
   additional WPLTO for the joint card. No halt if the walls hold.
