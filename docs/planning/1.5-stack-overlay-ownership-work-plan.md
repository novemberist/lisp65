# 1.5 work plan — stack/overlay and resident-geometry ownership

Status: **commissioned 2026-08-04** (owner decision at the 1.4 fallback:
park the parity pilot, commission this block as its named reopening
path). Reviewer charter below; Codex drafts the phased plan against it.

## The one sentence

The static-stack/overlay floor and the resident placement of shared
runtime primitives stop being LTO-derived accidents and become
explicitly owned architecture — so that a required, host-green fix
(today: the DMA content-convergence primitive) has a place to live
without geometry negotiation.

## The four evidence points (the class conviction)

1. Link 36: a pinned overlay boundary depended on the LTO-derived
   compiler stack profile.
2. The read-line DEL cards: three partitions produced compiler-owned
   `.noinit` shapes of 3/4/12 bytes against the contracted six.
3. The Link-91 first red: an unowned 20-byte descriptor surfaced in the
   phase slices.
4. The compact-form first red: `.noinit` drift `$C34D → $C51E` into the
   C2D overlay.

## Charter bounds

- The sealed v1.3.0 product identity is untouched history; this block
  works toward the next release line.
- Success criterion, binding: the convergence primitive (resident
  kernel, find-first-difference discriminator, routing protection for
  all sweep-named consumers) fits the resulting structure host-green —
  that is the gate that reopens the parity pilot.
- House rules unchanged: host-first, execution witnesses,
  dependency-sharp first red, sentinel/tag witness discipline,
  independent oracles, two owner halts.
- No resident-capacity negotiation by partition tricks; ownership means
  named owners, contracted floors, and gates that fail loudly on drift.

## Phase order

**A → B → Halt 1 → C → D → Halt 2 → parity-pilot handback.**  Phases A and
B create no product bytes.  Phase C implements exactly the layout selected at
Halt 1.  Phase D gets one product-shaped WPLTO card, not a sequence of
optimizer experiments.  A green Halt 2 satisfies the parked pilot's reopening
condition; Link 91 and its first device contact remain work of the resumed
pilot, not a hidden tail of this architecture block.

## Phase A — establish the ownership truth (read-only artifacts)

Build one machine-readable ownership inventory from the final Link-88/90 ELFs,
their linker scripts and maps, the three DEL First Reds, and both Link-91 maps.
The inventory must name, for every relevant byte range:

- VMA and LMA, size, alignment and section owner;
- lifetime: boot-only, always-resident, session-only, phase-only or overlay;
- simultaneous-live peers and every caller/callee crossing the range;
- whether placement comes from an explicit contract, an orphan rule, ordinary
  section order, or llvm-mos's generated `.noinit..Lstatic_stack`;
- every descriptor and scratch byte used by the convergence path, including
  the fixed 20-byte primary D705 job and the current named 40-byte probe pair.

The output includes the four conviction witnesses as fixtures, not prose:
Link 36, DEL shapes 3/4/12, the phase-slice descriptor failure, and compact
Link-91's `$C34D → $C51E` movement.  It also answers two reachability questions
before layout design begins: which E000 bodies are genuinely reachable after
boot, and whether any proposed overlay service would recursively require the
refill seam needed to load itself.

Exit: one inventory receipt with an execution witness and mutations for a
missing section, owner, live peer, descriptor and call edge.  No source
partition, product compile, WPLTO or hardware contact occurs in A.

## Phase B — contract and price the structural choices

Write the permanent resident-geometry ownership contract.  Its invariants are
independent of whichever layout wins:

1. The compiler static stack lives inside a named arena with an explicit VMA
   and capacity.  The first overlay floor is a contract constant; it is never
   calculated from the current `__noinit_end` or current LTO stack size.
   Synthetic final ELFs with 3-, 4-, 6- and 12-byte compiler stacks must keep
   the same overlay floor (or fail only against the declared arena capacity).
2. Shared resident services have named code and state owners, an explicit
   call ABI and a KEEP-ed final-ELF section.  Ordinary `.text`, `.bss`, orphan
   placement and phase-slice reachability are not owners.
3. The convergence service has one routing authority.  All four VM refill
   paths and all sweep-classified content consumers either enter it or retain
   an already-proved independent oracle.  Its source probe cannot use submit
   return as source truth.
4. Code, descriptors, scratch, static stack and overlays are checked as a
   simultaneous-live set.  Separate per-section fits do not constitute a fit.
5. Any overlay-backed candidate proves a non-recursive bootstrap closure: the
   service is available before the first consumer and is not loaded through
   the seam it protects.

Price no more than three architectural candidates against the Phase-A
inventory, using linker-only layouts and micro-ELF stack fixtures rather than
whole-product C/LTO partition trials:

- a fixed low-resident service island plus a separate static-stack arena;
- an owned E000 service slot paid for by moving proven phase-/boot-only bodies
  to their already valid cold domains;
- an overlay service only if the bootstrap closure above is acyclic.

Every price names exact addresses, capacity, displaced owners, facade cost and
the complete simultaneous-live envelope.  A candidate that merely changes an
assertion, padding, compiler partition or inherited wall is rejected before
Halt 1.

### Halt 1 — choose the owned geometry

The owner receives the inventory, the candidate table and one recommendation.
The chosen row fixes the static-stack arena, overlay floor, shared-service code
and state ranges, facade ABI and cold-domain moves.  If no row fits without
dropping a proved consumer or changing product semantics, the block parks
here; no implementation experiment follows.

## Phase C — implement one selected layout, host-first

Implement only the Halt-1 row.  The linker generator and source annotations
gain named ownership primitives; there is no source-level LTO steering.  The
permanent gate must inspect the final generated linker script and linked ELF,
not merely find section attributes in source.

The class closer executes at least these positive cases:

- compiler-stack fixtures of 3/4/6/12 bytes with one invariant overlay floor;
- an arena overflow at capacity + 1 that fails closed;
- a shared primitive and every descriptor in their contracted sections;
- four refill routes and the 13-site DMA sweep with eleven protected content
  consumers;
- an acyclic load/call graph for every always-needed service;
- source/target convergence cases 8/8 and all 15 existing mutations.

Mutations must reject a derived floor, an orphaned primitive, ordinary-BSS
descriptor placement, one missing route, one overlapping live range, a
recursive overlay load and a gate that reads its expected addresses from the
source under test.  The gate is wired into `check-source` with a non-zero
execution witness before any WPLTO is permitted.

Phase C may build host and micro-ELF fixtures freely.  It creates no product
identity and uses no device.

## Phase D — one product-shaped ownership card

Run one fresh WPLTO from the Link-90 static plane with the compact convergence
freight and the selected ownership structure.  The card is green only if all
of the following hold together:

- the static-stack arena and overlay floor equal the Halt-1 contract exactly;
- every named code/state owner is present once at its contracted address and
  no ordinary section overlaps it;
- the complete convergence gate and 13-site sweep remain green;
- the fresh `parity-toy` Ship build executes host-side and verifies its media;
- Bank 2, Session, fixed-facade, interrupt and product-identity contracts do
  not drift outside the explicitly selected ownership moves;
- a clean reconstruction produces the same owned layout and byteidentical
  product-shaped artifacts.

A red card stops the block with exact section and live-set numbers.  There is
no second WPLTO, no address negotiation and no Link 91 inside Phase D.

### Halt 2 — reopening decision

Halt 2 receives the permanent-gate witnesses, the clean-rebuild comparison and
the one WPLTO map.  Green means the binding charter criterion is met and the
parked parity pilot reopens at its preserved state.  Its first next action is
the already named Link 91 successor followed by the unchanged visible-sprite
hardware question.  Red returns an ownership-block disposition; it cannot be
relabelled as a narrower convergence claim.

## Halt 1 return — priced fourth class (2026-08-04)

The bounded paper round is complete.  It performed no product build, WPLTO,
link identity or hardware contact.  The fourth class is an honest fit, so this
document returns to Halt 1 with one recommendation; Phase C has not begun.

The real Link-90 Bank-2 inventory is a 65,536-byte plane at physical
`$020000`.  Its six emitted owners occupy one contiguous 47,282-byte prefix:

| Owner | Offset | Bytes |
|---|---:|---:|
| stdlib | `$0000..$4945` | 18,757 |
| IDE | `$4945..$7E2D` | 13,544 |
| IDEX | `$7E2D..$89A9` | 2,940 |
| M65D | `$89A9..$999C` | 4,083 |
| buffer | `$999C..$9A04` | 104 |
| compiler carrier | `$9A04..$B8B2` | 7,854 |

Thus the measured headroom is **18,254 bytes**, not the earlier planning
shorthand of roughly 20 KiB.  The mapped service takes the next contiguous
1,499 bytes at physical `$02B8B2..$02BE8D`; existing product bytes displaced:
zero.  It deliberately spends 1,499 bytes owned by future persistent/transient
append capacity, leaving **16,755 bytes**.  A selected Phase-C layout must make
`$BE8D` the Bank-2 low-front floor so an append cannot cross the owner.

The complete 1,545-byte convergence body splits without narrowing protection:
the 46-byte `c2_dma_read_or_abort` error wrapper stays low-resident, while
`vm_code_load_converged` (682), `c2_edma_prepare` (142),
`c2_physical_read_converged` (480) and `c2_physical_source_byte` (195) form the
1,499-byte far body.  Structured relocations bind its only outside code calls
to `vm_code_load` (`$349A`), `__memset` (`$B696`) and
`c2_product_physical_copy` (`$EDDF`); none lies in the temporarily mapped CPU
block.  Its six external data owners likewise lie outside that block.

The MAP tuple is exact.  CPU `$6000..$7FFF` maps to physical
`$02A000..$02BFFF` with `(A,X,Y,Z)=($80,$24,$00,$80)`, exposing the service at
`$78B2..$7E8C`; restoring `(0,0,0,$80)` returns the current low map while
retaining the owned E000 window.  One micro ELF measures:

| Resident component | Bytes |
|---|---:|
| retained abort wrapper | 46 |
| two entry wrappers | 18 |
| shared map-enter | 19 |
| shared map-leave | 15 |
| **total** | **98 / 243** |
| **remaining** | **145** |

The ABI preserves A/X/Y/Z across map-enter, preserves the one-byte A return
across map-leave and re-establishes Z=0 at the C boundary.  The fixture binds
the emitted MAP/EOM bytes and rejects a 244-byte facade.  Five further
mutations reject a resident overflow, recursive bootstrap, hidden IRQ,
far-call into the hidden block and Bank-2 owner overlap.

Interrupt closure also fits.  MAP changes only block 3; zero page/CPU stack,
the `$D000` I/O block, and the owned IRQ/vectors in high block 7 remain visible.
The final Link-90 raster handler has no call into `$6000..$7FFF`, and the far
body's structured dependency closure has none either.  MAP suppresses
interrupt entry only through EOM and does not change the prior I state, so an
IRQ may run during the far body and return to it without losing either map.

Bootstrap is acyclic: the native suffix rides the existing
`c2-bank2-static-code-plane` media role, which the cold stager stages and
independently reads back before it stages/chains the resident PRG.  Installing
or exposing the service therefore does not traverse the runtime refill seam it
protects.  Both sides of the simultaneous-live envelope are explicit:
47,282+1,499 of 65,536 Bank-2 bytes, 1,499 of the mapped 8,192-byte slab,
8,192 bytes of temporarily occluded ordinary Bank-0 text restored before
caller return, the 98-byte facade, and the already fitting 68-byte state,
2-byte marker, 2-byte fixed-ZP scratch and 12-byte static-stack arena.

The complete candidate table is therefore **1/4 fits**:

| Candidate | Result |
|---|---|
| fixed low-resident island | red, 1,302-byte contiguous deficit |
| owned E000 slot | red, 1,491-byte deficit |
| C356 overlay service | red, 1,524-byte live deficit plus recursive bootstrap |
| **mapped Bank-2 far service** | **green: 98/243 resident, 48,781/65,536 Bank 2, acyclic** |
