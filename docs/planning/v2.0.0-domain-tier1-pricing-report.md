# v2.0 domain discipline Tier 1 pricing

Status: **priced — one Bank-2 product card recommended; no WPLTO or link**.

## Population and result

Tier 1 is the 22-name resident library population whose delivered
implementation walks a list spine with `cdr`:

`append`, `assoc`, `butlast`, `copy-list`, `count`, `every`, `filter`, `find`,
`getf`, `last`, `length`, `mapc`, `mapcan`, `mapcar`, `member`, `nth`, `nthcdr`,
`position`, `reduce`, `remf`, `reverse`, and `some`.

`filter` is already strict in the materialized v1.9/v2.0 product; it remains in
the population as a zero-delta positive control. The other 21 currently treat
at least one finite foreign spine as an empty list or read fields from it.

The recommended form replaces the existing public objects and their existing
private traversal helpers in place. Every non-`nil`, non-cons termination calls
the already delivered `%list-malformed-error`. It introduces **zero names** and
does not add a second whole-list validation pass.

The signature-faithful matrix is green for 22 invalid-spine cases and 22
positive cases. Every invalid case ends in the target type-error channel; every
positive result is text-identical to the predecessor.

## Contract projection

The existing six-domain uniform-vector table moves as follows:

| Classification | Before | Tier-1 successor |
|---|---:|---:|
| error raised | 483 | 545 |
| documented permissive | 179 | 179 |
| silently wrong | 172 | 110 |

Thus Tier 1 removes **62** of the 172 silent cells. Sixty-five semantic cells
change in total: 62 silent results become errors, and three already erroneous
uniform calls change error priority from an invalid function designator to the
invalid list spine. No documented successful result changes. The remaining 110
cells belong to Tier 2 (`car`/`cdr`), numeric comparisons, string/buffer entry
points, or heterogeneous calls in which the uniform fixture does not supply a
list argument (notably one-argument `mapcar`/`mapcan`). The per-signature matrix,
not the uniform fixture alone, is therefore the Tier-1 conformance authority.

The audit has one inherited checker pin: its stable projection currently also
locks host VM step counts and diagnostic detail, although its sealed rule and
report promise classification plus target result/error. The product card must
convert that projection before updating the contract. Mutations that flip a
classification, result or target error remain mandatory; only host diagnostics
leave the public contract.

## Exact price

| Resource | Before | After | Delta |
|---|---:|---:|---:|
| resident stdlib bytecode | 18,664 | 18,990 | +326 B |
| composed static plane | 47,469 | 47,795 | +326 B |
| largest contiguous Bank-2 hole | 16,197 | 15,871 | −326 B |
| symbol slots | 109 | 109 | 0 |
| namepool bytes | 1,486 | 1,486 | 0 |
| ordinary text / E000 / BSS / Far Service | — | — | 0 |

The largest object in the whole successor stdlib is 253 bytes, still below the
255-byte object ceiling. The largest changed Tier-1 object is `nth` at 77
bytes. Capacity remains far above the 32/384 device floor.

On small positive host representatives, the largest extra costs are `mapcan`
+84 VM steps, `nthcdr` +54, `append` +46 and `mapcar` +40. These are pricing
figures, not a device timing claim. They buy fail-closed behavior without a
separate preflight traversal; a shared guard would necessarily walk the same
list twice and add a named helper.

## Recommendation

Open one product card for the in-place fail-closed termination form. It needs
no capacity exception and no resident-cost word. The card must materialize the
successor contract, prove every positive/negative signature case against the
final product artifacts, and carry the contract-projection conversion above.
