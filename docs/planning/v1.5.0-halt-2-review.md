## Outcome first

v1.5.0 is release-ready. The owner-observed MEGA65 session passed D1–D5 on
the exact selected media: visible boot progress, `WORKBENCH 1.5.0`, clean
prompt handoff, `trace`/`untrace` with exact BCODE restoration, `defstruct`,
the widened direct-expression path, bounded performance smokes and the user
symbol/name headroom contract.

The release notes state that five-second cost and the new progress display.
The REPL guide also states the existing line semantics: forms are evaluated
left-to-right, so completed earlier forms remain effective if trailing input
has a reader error.

[`docs/releases/1.5.0.md`](../releases/1.5.0.md).
