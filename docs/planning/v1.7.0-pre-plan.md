# v1.7.0 pre-plan

Status: **historical — sealed after v1.7.0 publication**

This is the post-v1.6 cutting surface. It records paid evidence, dependencies
and a rough order; it authorizes no product source change, link, medium or
device contact. The owner opens v1.7 by choosing a bounded first block.

## Starting world

v1.6.0 ships the cursor-aware `v16core` line editor and five independent
product fixes: verified MAP-CPU boot refill, packed-facade media proof,
execution-boundary recovery with sanitized control state, hardware-queue
single ownership, and the transitive MAP-nesting prohibition. Comfort was
removed as a unit, not partially shipped.

The restart evidence is the sealed `(repl)` fault file: the v1.6
display-entry, primary-VM-type and refill-seam attributions plus the complete
Input-Fidelity chain in the sealed v1.6 plan. Diagnosis and acceptance are
different worlds. Reproduction starts with the diagnostic world; a deliverable
claim is made only on a clean product world with all diagnosis-only freight
absent.

Current selected-product capacity is generous in symbols but uneven in code:
105 symbol slots and 1,413 name bytes free; 273 ordinary text bytes; 11
far-service bytes; E000 195 bytes total with a 159-byte largest hole; and 47
bytes in the 371-byte mapped product-cold arena. These are starting facts, not
budgets promised to a feature.

## Suggested order

1. **Comfort REPL completion.** Restore capture, adaptive hybrid service,
   balanced multiline input, history, prompt and composed-display ownership as
   one freight set. Begin from the sealed fault reproduction. Preserve the
   measured responsiveness/loss/normalization walls, the final-ELF claim rule,
   the single-owner queue rule and the clean-product separation. Resolve the
   remaining public `key-event` interaction while capture is armed.
2. **`INIT.L65` and canonical prompt swap.** Auto-load a removable default
   composition from the writable work medium; end in `(repl)`. Comfort becomes
   `lisp65>` and the native C recovery prompt becomes visibly exceptional.
   Missing or broken init must still reach the native prompt.
3. **Editing-surface polish.** Price the shared parenthesis/quote matcher and
   blinking cursor across line REPL, Comfort and IDE. The matcher uses the
   existing shared scanner; both features pay the actual per-key service-time
   cost before implementation.
4. **IDE service time.** Measure the full-screen path before pricing it. Reuse
   the adaptive drain/edit/render pattern only if the measurement says it
   dominates; do not inherit the one-line editor's timing as an estimate.
5. **Boot snapshot.** Price a world-bound, CRC-verified cache of the published
   post-library state, with full decode as invalidation fallback and the
   journal remaining the authority.
6. **Items 3 and 4 heritage.** Revisit the v1.6 Attic-write boundary and
   startup-lever work only after the earlier blocks establish their current
   geometry and value. They carry no inherited v1.6 delivery promise.
7. **Optional symbol-economy study.** The emergency has disappeared at
   105/1,413. Run this only if the default INIT composition projects meaningful
   pressure; then measure public/private names and directory-only
   anonymization before considering relocation.
