# 1.11 work plan — compiler carrier / emission locality

Status: **host-closed 2026-08-07 — headline reached** (owner direction
decision: another long autonomous host block before the release). No product,
link, device, packaging, public-surface, or release claim.

## The one sentence

Take the persistent-definition path meaningfully below the historical
180-second observation window by attacking what 1.10 proved
untouchable from the outside: the compiler carrier's emission shape
and cross-window locality — host-first, gate-walled, and with the
same honest-no exit if the pricing says the ceiling stands.

## Baseline and target

1.10 leaves the full defstruct sequence at a priced 716 s (218 s
after unchanged require). 1.10's ceiling analysis binds the residual
dominance: window events surviving locality-blind emission, and the
append cycles' fixed frames (sacred, out of scope). The headline
target is **< 180 s for the post-require section**; the honest floor
found by pricing is an acceptable result if it lands above that.

## Levers (priced before pursued)

1. **Carrier-level emission locality**: order and pack generated code
   objects so consumers and their callees share windows; price
   against the bound call-edge graph (the who-calls edge machinery
   from the comfort track is a ready instrument — 109 exact edges).
2. **Definition-freight shape**: the 182-byte generated definition
   after 1.10 still crosses windows per append; price a
   locality-aware freight layout.
3. **Window-geometry contracts**: only within existing owned
   contracts; no resident growth, no new architecture class.

## Phase A — exact price and graph closure

The exact 1.10 candidate was reconstructed as the baseline, including its
unchanged one-time require split. The comfort-track graph machinery remains
green at 109 exact shelf edges and was reused as an instrument pattern; the
compiler carrier has its own `directory_only.entry_refs` truth (306 exact
edges before the change). Pure carrier-object reordering was rejected before
implementation: `VM_CODEBUF=56` owns a window per CodeObject, so adjacent
objects do not share a live window across calls. A definition-freight wrapper
was measured at 259 s post-require and rejected as worse.

## Phase B — carrier-local emission fusion

The host-only locality overlay owns one raw-equivalent `%lcc-emit-local`
constructor at the four hot emission seams. It is deliberately separate from
the live product profile, so this no-link block cannot stale or silently rebind
the sealed v1.3 carrier. Ten small private helpers are packed inline (73
executed expansions), and the tail dispatcher tests its hot macro/generic-call
exits first without changing any predicate or lowering body. Larger helper
fusion was rejected by the existing 8-bit branch and 255-byte CodeObject
contracts. The frozen v1 `lib/lcc.lisp` is byteidentical to the owner-commission
commit.

The candidate reduces the carrier graph from 306 to 270 exact edges. Carrier
code grows 280 bytes, but nine directory objects disappear; directory freight
falls 63 bytes and the complete external Bank-2 image falls **336 bytes**
(`19588 → 19252`). Resident delta is zero.

## Phase C — semantic and pricing closure

The exact Link-82 reconstruction was run with the 1.10 defstruct candidate
against both carriers and with both windowed and direct lanes. All 11 emitted
forms have identical source, nargs/nlocals/flags, named literals, payload,
encoded length and result after normalization. Raw host-object SHAs are not
claimed: removing private directory entries renumbers internal host heap
symbols even when their named literal semantics are identical. Nine
publish-last appends, rollback behavior, constructor `(point 3 4)` and final
`C2J CLEAR` remain unchanged.

| priced lane | 1.10 | 1.11 | delta |
|---|---:|---:|---:|
| full sequence | 716 s | **677 s** | −39 s |
| post-require | 218 s | **179 s** | −39 s |
| post-require window events | 6,597 | **5,242** | −1,355 (−20.54 %) |
| post-require VM instructions | 34,401 | **32,409** | −1,992 (−5.79 %) |

The headline is therefore met on the unchanged conservative ruler:
**179 < 180 seconds post-require**. This is a structural price, not a target
wall-time or completion-upper-bound claim.
