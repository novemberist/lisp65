## Hardware acceptance

The native INIT session used three artifact-only media variants over the same
product pair. The absent variant reached the ordinary banner and prompt. The
valid variant established and later returned `17`. The failing variant printed
`*** vm: type error`, returned to one usable `lisp65>` prompt without retry,
and evaluated `(list 1 3)` as `(1 3)`.

The same contact supplied the Recovery-A0 perception row: error to prompt was
"practically immediate". This is the physical observation for the derived
empty-journal fast path; it is not promoted into a general boot or recovery
latency ceiling.

The release D-session displayed `WORKBENCH 1.7.0`, ran four performance-smoke
bodies at zero measured frames, and measured D5 at 113/1,506. The optional
`v16core` role is delivered but was not loaded in that release configuration.
Its favorable 8-slot/93-byte difference from the v1.6 loaded-library world is
fully attributed to the eight NUL-inclusive names belonging to that optional
package.
