### Phase-R disposition — 2026-07-30

**Complete; read-only, product delta zero.**  The current map has nine
prefixed domain modules plus one optional façade.  `m65-hw` remains P1, with
a 2,048-Bank-2-byte pilot envelope and no resident or native debit; the pilot
still waits for the 1.3 ship builder.

The parity substrate changed materially since the pre-1.0 design: Buffer,
bitops, typed `key-event`, C2 direct execution and the product-owned raster
counter are delivered facts.  Full word access is therefore reopened only as
a two-byte little-endian Buffer API; the old Fixnum `peekw`/`pokew` surface
remains tombstoned.

The four required outputs are bound:

- the Color-RAM body is 622 B code plus 20 B state in the current compiler;
  512-B packing makes that a 1,024-B allocation, 911 B beyond the 113-B
  Session remainder before catalog/dispatch freight, and the old four-job
  body predates the L10 completion contract — not affordable in 1.2.4;
- `(time)` uses the atomic product frame counter at `$FF83/$FF84`, nominally
  20 ms/frame, with no new native seam; M4 supplies the target calibration;
- a tick callback may run only after a rooted compiled-VM continuation yields
  `VM_YIELD_SAFE` to a top-level scheduler — never from IRQ, `lisp_poll`,
  nested evaluation, GC, transaction or overlay lifetime;
- the paper-only `m65-hw` pilot has a clean-build/package, host-oracle,
  capacity, bound-artifact parity and later hardware acceptance contract.
