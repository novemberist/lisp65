`probe_definitions` default.  The qualified v2.0-r4 predecessor carries 35

- CRC convergence was absent.
- Target emitter geometry collapsed to the host form.

The candidates' static plane and live direct-entry successor were both bound
correctly.  This is an invocation/configuration defect in the new product-card
driver, not a Block-3 product defect.

`resolved-profile.txt`, passes them as `probe_definitions`, and records the same
set in the successor contract.  The derivation checks both the exact population
size and the required Capture and first-fault members.  It has not been run.
