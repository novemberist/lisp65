# C2.1 full-composition host emission

Status: **full streaming host execution and sliced C target link passed; product substitution link not run**

Date: 2026-07-19

Machine-readable contract: `config/c2i-v2-contract.json`

The owner-approved C2I-v2 contract has now been applied to all six generated
product manifests. The emitter normalizes the code regions by zeroing the
literal-shaped words and derives every entry, descriptor and string record from
the generated manifests.

The current `literal_index` inputs are complete topological permutations. For
each entry, internal list tails are emitted before its root range, so the
entry's resolution base/count remains contiguous. The list head occupies the
legacy root position. A separate sharing fixture proves that two pair edges to
one descriptor retain the same descriptor identity.

## Provenance boundary

Every legacy SYMBOL becomes kind 8, including spellings that happen to match a
declared export. Kind 5 remains zero in this conversion because the legacy
artifact carries no compiler edge provenance. Tree-shaking, `who-calls`,
ide-help cross-references and future call-graph consumers may read only kind 5.

## Negative matrix

Fifteen mutation classes cover both version directions, pair self/forward
references, kind-8 flags, length, offset and name canonicality, undeclared
kind-5 targets, the forbidden spelling-to-provenance inference, zero entry
length and bad magic. The historical C2I-v1 proof remains intact and rejects
the new bytes.

## Claim boundary

This is a host architecture proof. It changes no product byte and authorizes no
capacity. The independent target boundary below is separate; a real product
link and device execution remain unproved.

## Independent target boundary

An independent C implementation consumes a compact contract-derived vector
containing one complete entry, kind 8, a shared descriptor, two backward pairs,
the L65S-v4-direct envelope and C2D-v1 bound to the same region offsets and
lengths. It passes as a native host executable and links with the pinned
llvm-mos MEGA65 toolchain.

The standalone link contains 4,274 bytes of text and 80 bytes of BSS. This is
not the product cost: it includes CRT, a test harness and unsliced validation
functions. It is retained as an upper-bound input to the substitution link, not
as a capacity debit. The MOS artifact was not run on hardware.

## Complete streaming boundary

The product-shaped decoder now consumes the complete 69,754-byte shelf through
a `u24` read seam and the complete 10,480-byte mutable C2D plane through bounded
`u16` reads and writes. Ten ordered phases validate the envelopes, bind the
regions, resolve all 2,249 descriptors and publish only after the last
resolution exists. The persistent phase context is 36 bytes and retains no
pointer into Attic or Bank 5.

The host witness materializes 116 strings, interns 979 symbol requests to 344
unique symbol identities, and allocates 168 cons pairs. Equal kind-8 spellings
therefore share identity; only kind 5 can cross the call-evidence seam. Pair
resolution remains one ordinal pass with no recursive walk.

Eight full-file mutations are rejected by the same streaming implementation:
C2D magic, shelf magic, catalog CRC, a v1 image presented to the v2 decoder,
zero entry length, kind-8 flags, and pair self/forward references. Mutations
below the shelf catalog have their enclosing CRCs repaired first, so they reach
the intended decoder phase instead of being caught incidentally by an outer
checksum.

The pinned llvm-mos link splits the decoder into ten independently loadable
runtime phases. Their sizes are 791, 775, 1,203, 1,050, 719, 1,218, 1,622,
1,682, 1,126 and 202 bytes. Every phase fits the existing 1,792-byte slot; the
tightest has 110 bytes of headroom. Two varied target links produce identical
PRGs and identical phase sizes.

This is still a proof artifact. Its five I/O/object callbacks are a link
harness, not the product's Enhanced-DMA, Bank-5 or allocator bindings. No
product capacity has been measured or authorized, and the artifact has not run
on the device. The next gate is the real product-layout substitution link that
retires all 28 L65M materializer slices and the Bank-0 directory arrays.
