## Product contract

The public surface is:

```lisp
(random n)
(random-seed seed)
```

`random` accepts a positive fixnum from 1 through 16383 and returns a
fixnum in `[0,n)`. `random-seed` accepts any signed 15-bit fixnum and
normalizes it to 14 bits. Equal explicit seeds produce byte-identical
55-slot states and equal output sequences.

The generator is an additive lagged Fibonacci sequence:

```text
X(n) = (X(n-24) + X(n-55)) mod 16384
```

The ring is represented by a proper 55-element Lisp list and a Lisp cursor.
They live only in the canonical symbol values `%random-state` and
`%random-index`. There is no native shadow state, resident cell, new
resident GC root or runtime-overlay record.

Range reduction uses rejection sampling. Plain `value mod n` is forbidden:
it biases every range whose size does not divide 16384. The permanent
fixture uses seed 7286 and `n=1000`; the first raw value is 16001 and must be
rejected, the next is 3179, so the required result is 179.

The lazy initial seed reads VIC raster `$D012`, CIA1 timer-A low `$DC04`,
CIA2 timer-A low `$DD04` and SID voice-3 noise `$D41B` through the existing
`peek` primitive. It consumes no key and creates no second input-queue
truth. `random-seed` remains the authoritative route for reproducible games,
tests and debugging.
