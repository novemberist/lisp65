## Why this recharter is not attempt number seven

Every prior death was machinery, never geometry — and both machines
have since been rebuilt and battle-proven on the Link-97/98
qualification and card series:

- **Acceptance** is the reviewed golden-layout inversion: one exact
  SHA-bound comparison, no checker pipeline, no vocabulary, no
  meta-levels (12 mutations, order-independence proven).
- **Production** is the inverted producer: SHA-bound input closures,
  candidate-preflight profile projection with additive provenance,
  real-consumer selftests, published callees, process isolation,
  media-pair identity — every clause paid for by a named first red
  and guarded by its mutation.
- **The vocabulary** is complete by construction: sections, ABI
  policies, driver gates, successor identities — the union of the
  three parks' case law, all live in check-source today.
- **The geometry** is proven: the 1.7/1.8 inventories and the final
  cards' zero-deficit layouts are the binding substrate; the golden
  artifact records exactly that truth.

## Convergence granularity review — current DMA API requires per-read proof 2026-08-14

The tempting source-span argument does not survive the destination boundary.
The Shelf is already authenticated as one catalog, six code spans and six
metadata spans, but the F018B defect is not corruption of that immutable
source.  It is independently stale visibility at the destination of a later
DMA.  A source CRC therefore cannot dominate a byte consumed from a future
ordinary DMA copy.  `CRC(source) == expected`, followed by an unverified DMA
read, is the exact class rule in a different order, not amortization.

The delivered implementation really pays the fine grain.  Its 1,180,781
payload bytes each trigger a two-job source-byte/marker probe: **2,361,562 DMA
jobs** before any primary copy, versus 346,298 naked logical read jobs.  That
is a structural minimum of 6.81945 jobs per former job (7.81945 if each
logical read also needs its one primary copy), plus polling and byte compares.
The historical `<20 us` value remains scoped to the non-equivalent two-byte
`vm_dma` path, so this ratio is a job-count result, not a fabricated wall-time
ratio.

The equal-safety alternatives were priced rather than hand-waved:

1. A verified destination cache is valid only while every consumer reads that
   retained cache.  The largest existing exclusive scratch is 304 bytes, so a
   256-byte line is the largest plausible power-of-two candidate.  Covering
   the 93,681-byte Shelf and initial 33,840-byte C2D would need 499 unique
   lines and 998 bytes of delivery-bound CRC16 freight in the impossible
   best case of one fill per line and no eviction.  Even that best case carries
   614.553802 seconds of formal 64-frame failure envelope.  More importantly,
   the largest image is 37,500 bytes and C2D is changed by 4,773 writes during
   the phase; image retention and mutable write epochs have no owner in the
   delivered design.
2. Delivery-bound direct string offsets can safely remove 297,068 redundant
   pool-header reads when a build gate proves every static reference is a
   record boundary.  It cuts Shelf calls from 338,151 to 41,083 and total
   converged calls to 49,230, but 586,645 destination bytes still require the
   same proof.  Its formal envelope remains 9.063947 days: a worthwhile later
   decoder optimization, not the granularity answer.
3. A synchronous CPU-visible transport could keep the existing image/span
   CRCs as identity proof and remove DMA-completion trust entirely.  The
   parked self-owned path prices a 2-KiB CPU-side Attic copy at well under
   1 ms at 40 MHz.  Link 106, however, has no target proof for Attic plus
   Bank-5 CPU visibility, and its accepted contract explicitly rejected an
   unproved flat CPU replacement.  That remains a separately commissionable
   architecture successor; it cannot retroactively price this candidate.

**Decision:** per-read destination proof is structurally required by the
*current stateless DMA API*, not by every possible architecture.  The second
commission exit therefore applies.  LOADING LIBRARIES is a product-facing
performance item; no honest expected duration exists until its exact device
rate is measured.  Another wait-only D1 is forbidden.

**Progress ring commissioned, not built:** a non-promotable diagnostic sibling
records a 32-bit count of successful standard convergence reads plus decoder
phase, image, entry/descriptor ordinal and publication ordinal into four
commit-last target-owned ringslots.  Sampling is target-side only while the
phase runs; one final stop and mapping-correct raw-first readback harvest it.
Owned-slot, 32-bit no-ABA, guard non-interference and tuple/seqlock proofs are
host preconditions.  Growing slots yield the actual rate and completion
estimate; fixed slots name the loop/stall neighborhood; READY closes D1.
No contact is authorized until that instrument is host-green.  D2–D5 remain
closed and no hang or correctness claim is made.
