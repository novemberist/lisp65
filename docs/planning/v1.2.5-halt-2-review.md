## Outcome first

v1.2.5 is release-ready. Link 82 repairs one deterministic ordering defect:
in v1.2.3 and v1.2.4, any ordinary persistent definition created before
`require` made the resolver reject the legitimate Session row and return
`nil` before consulting package media.

The correction keeps every persistent-row geometry check. Package size and
combined-identity checks now apply only to L65INDEX matches; a geometrically
valid non-index row is an ordinary Session definition. The C2D-v6 format is
unchanged. The fix adds 19 Bank-2 bytes and zero resident bytes, roots,
primitives, state or overlay records.

The complete reviewed wording is in
[`docs/releases/1.2.5.md`](../releases/1.2.5.md). The accepted product banner
remains `WORKBENCH 1.2.4`; v1.2.5 identifies this correction package and its
sealed artifacts.
