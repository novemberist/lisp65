# C2.2 L65R-v3 record-CRC contract

Status: implemented and WPLTO-proven, 2026-07-21. The later Link-36 attempt
stopped before product closure and selected C2-lite under the terminal-floor
rule. No L65R-v3 product was promoted or executed on hardware.

## First Red

The DMA-completion preflight proved that L65R-v2 record capture conflicts with
the transaction-authentication fast path. The first slice authenticates the
directory and publishes only its payload boundary, image limit and entry
count. Later slices deliberately skip that directory pass. They therefore
have no legal pass from which to capture their own 32-byte record. Re-reading
an unauthenticated record, re-running directory authentication for every
slice, or adding a persistent record cache would respectively recreate the
DMA race, undo the amortization contract, or spend unavailable resident state.

## L65R-v3 entry rule

L65R-v3 keeps the 32-byte entry size. The reserved u16 at bytes 22..23 becomes
`record_crc16`, computed with CRC-16/CCITT-FALSE over the complete entry while
those two bytes are logically zero. The sole emitter calculates and writes the
value as part of record emission. A zero value is a format error, never a
wildcard.

After `rtov_read` returns, a consumer treats the record as untrusted. It polls
the record's virtual-zero CRC until it equals the embedded nonzero value or
the common 64-frame convergence timeout expires. It never writes zero into
the live DMA destination to perform the calculation. Thus every later slice
can authenticate its one record read without repeating the aggregate
directory pass and without a second record representation.

## Version and decoder asymmetry

The product uses one L65R-v3 emitter and one strict L65R-v3 decoder. A v3
decoder rejects v2; no dual decoder, compatibility branch or migration path
ships. The version bump is free because L65R-v2 never left a device. The old
v2 `reserved-must-be-zero` rule is replaced, not weakened, by
`record-crc-must-be-valid`.

## Permanent proof boundary

The mutation matrix must reject a wrong record CRC, a zero record CRC, a
record that never converges within 64 frames, a v2 image presented to the v3
decoder, and any second site that emits the CRC. The record CRC is written at
emission only; target code validates but never invents it.

At authorization time the implementation probe used the canonical Link-33
profile and preserved the then-current 115-B `$E000` floor. Subsequent
convergence work explicitly rebound that floor to the terminal 63 B and
proved the complete strict-v3 package in WPLTO. The one authorized Link 36
then grew resident `.text` 10 B beyond that probe and overlapped the fixed
handoff by 8 B. It produced neither a Resident-Island seed nor a product
closure. The terminal self-destruction clause therefore selected C2-lite;
there is no Link-36 retry or further floor/anchor negotiation.
