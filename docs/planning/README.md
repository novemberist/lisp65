# Planning

Planning documents are not release promises. Capacity receipts and block
contracts govern implementation even after an owner plan is approved.
This directory belongs to the private planning record and is deliberately not
exported verbatim to the curated public repository. User-facing commitments
must be restated in the public roadmap or release documentation before they
are presented as product claims.
