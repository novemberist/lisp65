## Outcome

v1.2.5 repairs one deterministic ordering defect in `require`.  In v1.2.3
and v1.2.4, any ordinary persistent definition created before `require`
causes the resolver's world proof to reject that legitimate Session row and
return `nil` before it even consults package media.  The correction keeps the
C2D-v6 format unchanged:

- every persistent row must still pass source-kind, source-slot, generation,
  base-address and authenticated-size geometry;
- identities found in L65INDEX additionally pass package size and combined
  identity checks;
- geometrically valid identities absent from L65INDEX are ordinary Session
  definitions and do not invalidate the package world.

The narrowed rule is explicit: without a row-class discriminator, an
index-absent identity cannot be rejected merely for being index-absent.

## Standing execution rules

- First Red stops only its dependent branch.
- No format, resident, root, native-primitive or overlay change is authorized.
- Every device session starts with a cold reset and an asserted fresh state.
- A transfer with no log progress for 120 seconds is aborted.
- Hardware `require` evidence is valid only after the mounted medium is
  independently shown to contain L65INDEX and the requested package.
- `make check-source` must be fully green on the built candidate; no exception
  list is authorized.
