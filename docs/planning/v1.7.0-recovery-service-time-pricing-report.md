# v1.7 recovery-service-time diagnosis and pricing

Date: 2026-08-27

Scope: Block R, host-only

Status: graduated model; implementation remains closed

## Outcome

The synchronous stall is not an unexplained delay.  In the sealed empty-C2J
world the serial abort driver performs eight transported overlay calls:

1. abort control;
2. journal validate;
3. journal reconstruct;
4. abort control;
5. roots/fronts;
6. abort control;
7. journal/rollback prepare;
8. abort control and done.

Every call first loads and CRC-checks the 1,434-byte record verifier and then
loads and CRC-checks its target.  The empty path therefore folds **17,852
CRC bytes** and executes at least **1,376,050 instructions in `rtov_crc_mem`**.
That number deliberately excludes physical reads, verifier execution, phase
bodies, wipes and call glue; it is a lower bound, not a timing projection.

The model graduates against all of the stopped CPU state, not merely the two
lengths.  At PC `$22C5` the 763rd byte of the record verifier is in its second
CRC bit.  The model produces pointer `$C650`, remaining length 671, A `$43`,
Y 7 and live CRC bytes `$EA/$86`, exactly as captured.  The apparent
pointer/count mismatch is the instruction order: length is decremented before
the byte is folded, while the pointer advances only after all eight bits.

## Priced menu

All code sizes below are exact llvm-mos emissions of stand-alone target
micro-prototypes.  They price the named mechanism core; call-site integration
and final placement belong to an implementation card.

### A0 — empty-journal bypass

Read all 64 C2J bytes into exclusive phase scratch.  When every byte is zero,
bypass validate/reconstruct and the abort-control choreography, then run only
fronts and rollback-prepare.  Any read failure or nonzero byte takes the
unchanged slow path.

- code: **51 bytes**;
- state: **0 bytes**;
- empty-path residue: two overlay calls, 6,110 CRC bytes and at least 471,197
  CRC instructions;
- reduction: 65.8% of the measured CRC lower bound.

This is the small fallback form.  It is safe and cheap, but it leaves two
indivisible verifier/target CRC pairs before the prompt.

### A — complete derived quiescence fast path (recommended)

Prove that there is no recovery obligation from the complete zero C2J, the
generation-bound C2D header/front watermark and the top transient image row.
The probe reads 64 + 48 + 32 = **144 physical bytes**, reuses phase scratch,
and returns immediately only for the fully derived no-journal/no-transient
case.  Any uncertainty falls through to the unchanged serial driver.

- code: **304 bytes**;
- state: **0 bytes**;
- quiescent-path overlays/CRC bytes: **0 / 0**;
- authority: born-derived; no shadow dirty bit or transient-depth cell.

This is the technical winner.  Its implementation card must still price a
permanently visible placement for the 304-byte probe; this study does not spend
that capacity.

### B — defer the existing driver

Render the native prompt, set a pending byte, and invoke the existing driver
from an idle seam.

- scheduler core: **25 bytes**;
- state: **1 byte**;
- recovery work: unchanged 17,852 CRC bytes / 1,376,050-instruction lower
  bound after the prompt.

This changes the time at which the stall is seen, not its service cost.  Each
overlay call remains indivisible.  It is dominated unless runtime-overlay
transport itself becomes resumable, which is a substantially larger change.

### C — resident obligation ledger

Maintain journal-active and transient-depth cells at every publication and
clear edge, then answer the common case in O(1).

- mechanism core: **22 bytes**;
- state: **2 bytes**;
- integration not included in that small core: every writer edge,
  failure-stickiness, boot initialization and C2D reconciliation.

Although fast, this recreates the second front/depth authority that the v5
contract deliberately removed.  It is structurally dominated by A.

## Recommendation and gates

Recommend **A, the complete derived quiescence fast path**, with A0 retained as
the placement fallback.  A future implementation card must prove:

- all 64 C2J bytes and the generation-bound header/front facts are consumed;
- nonzero C2J and a transient top row both take the existing slow driver;
- read or identity failure also takes the slow driver, never the fast return;
- the final ELF places the probe before the first overlay call.

This report authorizes no product edit, WPLTO, product link, medium or device
contact.  Comfort and Block 3 remain closed behind the Block-R review outcome.
