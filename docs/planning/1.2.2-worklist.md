Ground rules unchanged: host-first, receipts, SHA binding, claim hygiene,

Ordering rule this cut: **cheap answers before expensive campaigns, and the

## Phase D — Diagnostics and one free question (priority 1)

D1. **DIRMISS renderer fix.** Attribution is complete: the L65E consumer
    overwrites the correct pointer return with incidental A/X. Implement the
    two-store correction, add a fixture that renders a *full* undefined-
    function name end to end (not merely a non-empty string), WPLTO, and
    carry it in the next product link. Rationale beyond the cosmetic: the
    truncated name cost this project several days of hardware hunting; a
    diagnostic that lies is worse than none.
D2. **The free `defstruct` question.** v1.2.1 masks Ethernet, Auto-IEC and
    audio DMA — precisely the three sources that R-1 named as the remaining
    candidates for the `defstruct` fail-closed frame (F011/SD were refuted:
    no CPU IRQ edge in the pinned core). **One REPL line therefore answers
    whether `defstruct` is unparked at zero cost.** Add it as a line of the
    next bundled session: `(require 'defstruct)` then `(defstruct point x y)`
    then `(make-point 3 4)`.
    - Green → the library era reopens and R-1 is closed with an attributed
      cause; the candidate list (sort, parse-integer, fixed point, ring
      buffer) becomes reachable again.
    - Red → the observation stands, R-1's remaining candidates are exhausted,
    and the restart package gets a new named question. **No hunt is
    authorized by this line**; a red result returns as a Class-C decision.

    **Terminal disposition, 2026-07-29:** Link 78 reproduced the red
    fail-closed frame. The owner then commissioned one final blackbox with a
    hard budget of one WPLTO, one successor link and one hardware run. Its
    65-byte terminal capture body fit ordinary Bank-0 text and preserved the
    E000 window byte-for-byte, but the WPLTO closure correctly rejected the
    direct E000-to-Bank-0 edge. A legal new fixed facade needs 3 bytes while
    the fixed block has 2. No second form, link or hardware run is authorized.
    `defstruct` is therefore **permanently parked for this era**; Link 78
    remains the product authority. Receipt:
    `c2.2-v1.2.2-fail-closed-blackbox-terminal-first-red.json`.
→ **Class-C halt D:** WPLTO card for D1 reviewed, then one link, then the
   bundled session carrying D1's smoke and D2's three lines.

## Phase G — The GC campaign (priority 2, instrument first)

G1. **`gc`/`room`/`error` trio — the instrument.** Parked freight from the
    F-phase (cold carrier measured 2,552 B against the 1,792 B slice cap).
    Re-cut it with a semantic split; contract unchanged (shared carrier, no
    resident dispatcher). It is the natural instrument for every memory
    question and has now been the missing tool twice.
G2. **GC envelope attribution.** Valid isolated observations are 88 frames
    (Link 66) and 89 frames (final G5), one collection and 96 contract root
    block reads each; ≥576 DMA jobs are proven. The mark/sweep split has
    never been measured. With `room` available, attribute the envelope into
    named terms: root scan, mark traversal, sweep, EXT block transport.
    Preserve unknown phase times as unknown.
G3. **Cut only if the attribution justifies one**, with a scope number and
    the usual walls. No speculative optimisation.
→ **Class-C halt G:** attribution reviewed before any cut is commissioned.
