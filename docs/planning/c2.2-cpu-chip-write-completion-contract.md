# C2.2 CPU→Chip write completion and abort restoration

Status: Owner-confirmed four-point minimal form with emission-bound C2J seal,
non-LTO stateless mode-derived transfer length and single-submit readback,
2026-07-26.

Cutpoint 4 showed that logical rollback and physical rollback were different
truths. The predecessor header and C2J bookkeeping were restored, while nine
Bank-2 code bytes and two Bank-5 export-journal bytes arrived only during the
Freezer roundtrip. A submitted DMA write is therefore not a completed write.

The canonical contract order is:

1. write and independently prove C2J ACTIVE before the first mutation;
2. submit transaction writes without producer-local convergence loops;
3. at publish, run one gathered data barrier and target proof, then
   independently prove the header before `committed`;
4. at abort, run one gathered data barrier before the first restoration or
   wipe;
5. after success or complete restoration, write and independently prove C2J
   CLEAR last.

This is four converged points: two amortized transaction-data barriers plus
two journal bookends.  The bookends are not data barriers.  They protect the
ability to prove and perform recovery: an ACTIVE record that has not landed
leaves an abort without a journal, while an unproven CLEAR can leave stale
ACTIVE state or can arrive late enough to erase the following transaction's
new ACTIVE record.

Completion is content-defined. The expected bytes and readback bytes are
disjoint. The destination is poisoned to a value unequal to the expected
content exactly once, then exactly one ordered trailing target read is
submitted. The CPU samples only that local destination until equality or the
bound of 64 frames. A retry must neither poison again nor resubmit the read:
Link 64 proved that a result delivered after the immediate comparison can
otherwise be erased at the start of the next attempt and remain invisible for
the complete timeout. Reusing the source buffer as the read destination is
forbidden: that was the blind spot in the Bank-2 stage.

The transfer length has no storage authority.  Completion has exactly two
content domains: ACTIVE, rollback and CLEAR operate on the 64-byte C2J;
Publish operates on the 48-byte header.  The common body derives that constant
from the completion mode immediately before the one poison pass, before the
one target DMA, and before comparing the local result on every attempt.
Caller-supplied length,
llvm-mos `__rc*` scratch and phase-scratch bytes are all forbidden authorities.

The derivation is the named, sized assembler function
`c2_completion_mode_length` in the append-header section.  Its target ABI is
mode in A and length in A, with Z restored to zero.  It contains only the
admitted mode comparisons and the constants 48, 64 and fail-closed zero; it
does not read or write memory.  The final ELF must retain exactly one such
symbol and four direct call edges: initial validation, pre-poison, pre-DMA and
post-read/pre-compare. The timeout retry returns only through the
post-read/pre-compare call; returning through poison or DMA is a permanent
red.
Inlining, disappearance of the symbol, another caller, a mutable load, or a
retry edge that bypasses rematerialization is permanently red.

This closes two successive hardware failures at their common root.  Link 62
entered with `$0040` but returned from the nested read with live scratch
`$bb04`.  Link 63 reloaded instead from `record[27]`, but that reused phase
storage was observed as `$fc` while Slot 39 remained ACTIVE.  The second gate
proved that reload instructions existed; it did not prove the ownership or
lifetime of their source.  The permanent negative fixtures now clobber both
call scratch and `record[27]`.  Neither mutation may affect the mode-derived
length, and an unbounded poison loop is always red.

The first WPLTO spelling of the stateless rule still used an always-inline C
helper.  Whole-program LTO erased the helper, kept the derived byte live in
`$1a` across `c2_stream_c2d_read`, and made the retry jump directly to poison.
That artifact was First Red before Link 64.  The non-LTO leaf removes the
optimizer from this proof boundary rather than asking it to preserve source
structure.

For C2J ACTIVE and the pre-rollback bookend, identity is bound at emission
rather than reconstructed at consumption.  The producer first finishes all 64
C2J bytes, including the existing CRC32/IEEE format field in bytes 60..63.  It
then computes one CRC16/CCITT-FALSE seal over the complete record with the
existing `rtov_crc_mem` assembler leaf and stores that seal in the
lifetime-free phase-scratch bytes `record[25..26]`.  The common bookend poll
reads the target into an independent poisoned buffer, computes the same leaf
CRC once, and compares it with the producer-bound seal.  Rebuilding and
comparing the twenty producer fields is forbidden.

Cold-boot recovery keeps the stronger format validation boundary: it checks
the on-record CRC32, identity, ranges and reconstruction relations first.
Only a validated 64-byte snapshot is resealed in `record[25..26]`; rollback
then consumes that seal exactly like a live transaction.  The seal bytes are
dead after the source-record CRC phase, remain exclusively owned through the
transaction, and are released only after a content-proven C2J CLEAR.  This
adds no state, pointer, root or BSS byte.

One common cold body implements both data boundaries and the two bookend
proofs.  It is invoked only by the resident serial driver; no overlay calls
another overlay.  The nine private poison/readback/timeout copies of the first
implementation are forbidden.  Producers submit ordered writes and preserve
only bounded touched-span facts.

The pre-header boundary covers the Bank-2 code interval, the Bank-5 C2D
suffix, export-plan scratch and symbol interning writes.  Header target
identity is proven before runtime publication.  Post-header export-journal
and symbol-function writes are dominated by CLEAR on success or by the
pre-rollback boundary on failure.  Rollback restoration and wipes are
dominated by the final CLEAR bookend.

The export area is transaction scratch. Its quiescent state is all zero, both
after success and after rollback. This makes exact abort restoration a
physical byte invariant rather than a counter convention.

The complete write inventory includes the emitter-root store and the Bank-5
symbol pool, name-offset, value and function-cell domains.  The emitter store
is ordered before ACTIVE; symbol interning is covered before header
publication; export and restoration cells are covered by the rollback
boundary and final CLEAR.  Attic cleanup is outside this Chip-RAM contract and
remains governed by the existing runtime-overlay DMA-completion contract.

The product-shaped probe may place code only in the cold Session overlays.
The resident C2D write seam and the `$E000` geometry must remain byteidentical.
The fixed walls remain: 32 bytes Bank-0 text noise reserve, `$E000` floor 54,
slice ceiling 1,792, and Session aggregate at most 65,536.

A green WPLTO result does not close C1. Hardware must repeat Cutpoints 3 and 4
against the successor identity and prove normal continuation plus byteidentical
Bank 2, Bank 3 and Bank 5 restoration before the matrix gate can fall.
