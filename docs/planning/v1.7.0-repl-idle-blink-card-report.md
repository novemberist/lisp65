## Bounded scheduling

The line surface owns a flat, preallocated idle record.  A delimiter starts a
prefix job without scanning a code unit.  `%rl-scan`, `%rl-close` and
`%rl-open` each invoke exactly one shared pass, and each shared pass derives
`min(stop, i + 3)` internally.  No caller can force a fourth code unit.

Ordinary input never enters the scanner.  A dynamic boundary fixture types an
ordinary character, crosses three empty polls and observes zero `%sexp-*`
calls.  Matcher state, two delimiter pairs and the blink cell are allocated
once when `read-line` starts; none of the ten idle-path objects calls `cons`,
`list` or another allocating helper.

States without the new slot 10 retain the old blocking or parked-Comfort
path.  This prevents card 2 from silently reactivating the descoped Comfort
freight.

## One composed framebuffer owner

The line editor clears its previous pair before every input handoff and forces
the cursor visible before dispatching that event.  On idle polls it installs
new matches through the single `%rl-idle` seam.  A composed trace over `(a)`
then cursor-left observes all three required facts in one framebuffer:

- the current cursor cell is attribute 129;
- its partner is attribute 7;
- the old partner is subsequently restored to attribute 1.

If the cursor itself is a delimiter, the hidden blink phase preserves
attribute 7 rather than erasing the match.  The forced phase writes attribute
129.  Card 1's live successor audit now admits exactly four external shared
edges — scan, open, close and paint — all from `%rl-idle`; no alternative
scanner or second paint owner exists.
