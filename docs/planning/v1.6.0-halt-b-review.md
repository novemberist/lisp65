## Hardware acceptance

The owner-observed Item-1 session used physical keyboard input, one form per
submission, zero post-boot automated accesses, zero observations during active
persistent forms and zero red frames. It proved insertion in the middle,
Cursor/Control movement parity, line endpoints, backward and forward deletion,
both boundary no-ops and ordinary native echo. The historical first-byte input
Red was absent.

The same session raised `(>= nil 32)`, printed `*** vm: type error`, returned
to `lisp65>` and evaluated `(list 1 3)` as `(1 3)`. This is the hardware row
for the shipped retired-overlay execution backstop with sanitized recovery.

D5 loaded only `v16core` and ran five physical rows. List read, list write,
string access and a published call each measured zero frames. One stopped-state
Bank-0 capture supplied the 105/1,413 headroom values above.
