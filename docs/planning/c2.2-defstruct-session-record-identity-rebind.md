# C2.2 defstruct session-record identity rebind

Status: host/media correction; no product link

Date: 2026-07-27

The canonical Link-71 product verifier has always required the fixed `SESS`
tag at bytes 0–3 of the sole L65S-v4 session record.  The first defstruct
media emitter instead reused the generic static-shelf builder's record-name
field and wrote `place` or `dfstrct`.  Its host decoder ignored those bytes,
so emitter and host oracle agreed with each other while disagreeing with the
linked product.  The earlier private build-ID mismatch stopped validation
before this second divergence became visible.

The session artifact has no record-local name namespace.  `L65INDEX` already
binds each canonical library name to its locator, combined image CRC, exact
capacity deltas and dependencies.  The one session emitter therefore writes
`SESS` plus zero padding into record bytes 0–7, recomputes the catalog CRC,
and its decoder rejects any non-`SESS` identity.  The permanent negative
fixture mutates the tag while repairing the catalog CRC, proving that the
identity check—not an incidental checksum failure—rejects the artifact.

Code, C2I metadata, per-region CRCs, combined image CRCs, artifact widths,
L65I rows and Link-71 product bytes remain unchanged.  Only the record tag,
the catalog CRC that covers it and the corresponding D81 sectors change.
The successor medium receives a new identity and must pass the same
artifact-side replay before any `require` or `defstruct` hardware claim.
