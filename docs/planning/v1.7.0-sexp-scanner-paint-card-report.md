## Resumability is structural

The price prototype proved semantics by synchronous calls.  The product form
does not inherit that weakness.  Scan, opening-partner replay and
closing-partner search are pure chunk transformers over surface-owned state.
An external call passes `edge=nil`; the function derives
`min(stop, i + 3)` once and carries that private edge through tail recursion.
Thus even a caller that supplies the full 250-code stop cannot make one call
consume a fourth code unit.

The executable cases cover both linked-list and packed-string sources,
two-chunk open/close and quote matches, strings, comments and escaped quotes.
All matcher cases allocate zero cells.  Three independent four-code mutations
— one for each pass family — are rejected.

The historical 0.48-frame figure remains what review required: a scheduling
projection from historical host instruction conversion, not current device
evidence.  This card records exact host instructions and bytes only.

## Paint ownership

`%sexp-paint` consumes the surface's old and new highlight pairs as one
transition.  It restores both old cells first, paints both new cells second,
and composes cursor reverse-video in the same operation.  The emitted trace is
byte-for-byte the expected four writes:

| Column | Row | Code | Attribute | Meaning |
|---:|---:|---:|---:|---|
| 0 | 4 | `(` | 1 | restore old point |
| 2 | 4 | `)` | 1 | restore old partner |
| 3 | 4 | `(` | 129 | new point and cursor; cursor wins |
| 5 | 4 | `)` | 7 | new partner |

An unmatched result passes `new=nil` and therefore clears the prior pair.
Mutations that strand the old highlight or let delimiter paint overwrite the
cursor both fall.  The permanent caller audit permits paint and pass entry
only from `%rl-idle` and `%ide-idle`; there is no external caller yet, proving
that activation remains deferred rather than silently synchronous.

## One emitted owner

`lib/sexp-depth.lisp` remains the single source.  The eight new objects are
emitted once by the resident Workbench stdlib.  The IDE library retains the
same source for its existing indentation helper but removes the eight shared
objects from its own emission and resolves them from the resident suite.
There is no second matcher identity whose load order could choose semantics.

The integration run exposed two historical-world assumptions.  The ship
input/wait suite now declares the existing `%ide-line-net-depth` helper as
IDE-only while retaining the eight shared objects.  The accepted Block-3
pricing receipt is also sealed at `7c8e4fc4`: its pre-freight source identities
remain historical evidence, while this card's live gate owns the successor
source, exact emitted sizes and capacity arithmetic.  The conversion did not
regenerate the accepted price or weaken any current product claim.

The full-chain run exposed the same assumption in five older consumers whose
historical library products share today's generated output paths.  The Link-93
trace ABI, v1.5 name-freight, Link-95 same-world media and Link-116 media checks
now reconstruct or bind their accepted evidence in its sealing era instead of
rebuilding it through the successor Workbench suite.  The Phase-1b Comfort
price keeps its sealed scheduling-step witness while rechecking the enduring
delivered-primitive claim in the successor world.  These are evidence-boundary
conversions only: none changes a product byte, accepted historical artifact or
