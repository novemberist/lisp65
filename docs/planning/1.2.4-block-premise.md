# 1.2.4 block premise — the fx / gfx-adjacent era

Status: **premise, owner-directed 2026-07-30** — superseded as commission
by [`1.2.4-work-plan.md`](1.2.4-work-plan.md) (2026-07-30, after v1.2.3
shipped); kept as the record of what the owner fixed.
This document only pins what the owner has already decided, so the block
starts sharp instead of with a scoping debate.

## Fixed by owner decision

1. **Core: `fx` (fixed-point).** Signed ~8.7 format
   (fixnum-width-bounded), hardware math unit `$D770+`, the legacy
   `lib/stdlib-fixed.lisp` stays superseded. The 1.2.3 Phase-D session
   carries the passive `$D770` probe; its result (which product-register
   bytes carry the fraction bits) is an input to this block, not a task
   of it.
2. **First item, before any `fx` code: the BASIC 65 parity revalidation**
   (the read-only paper pass the 1.2 scope memo commissioned). It answers
   the same questions the `fx` design needs anyway — EDMA surface,
   capacity model, `m65-hw` as P1, module graph with fidelity tags — and
   it must name the **tick-hook scheduling contract** as one of its
   outputs, because the timer-hook assumption is one of its five obsolete
   inputs.

## Candidates the block decides (not decided here)

- **Color-RAM scroll rider** (parked, register row of 2026-07-30): the
  28-bit `$FF80000` EDMA color path is the same surface the gfx modules
  need; the pre-1.0 prototype is hardware-green. Whether it rides 1.2.4
  is decided when the revalidation has priced that surface.
- **`(time)`** (parked, register row of 2026-07-30): independent of the
  tick hook — one readable time base around one evaluation, cold path.
  Cheap enough to ride once the revalidation pins the time base.
- **Tick hook** (parked, register row of 2026-07-30): the strategic
  unlock (MOVSPR/PLAY/SOUND-class parity together), but it needs its
  scheduling contract designed first — nested VM polling is not a safe
  callback point. The Phase-I interrupt-ownership work (raster as the
  sole owned IRQ, masked-source policy hardware-read-back) is the
  substrate it was waiting for. Expected shape: design contract in
  1.2.4, implementation earliest after it — never as a rider.

- **L10 re-measurement on the current core** (owner decision 2026-07-30:
  after 1.2.3, not in it). The 691 ms DMA-visibility curve that gates the
  C2-full return was measured on an older core; the instrument exists.
  Re-running it either arms the owner's L10 upstream discussion with
  current data or reveals that the C2-full gate is already open. One
  bounded measurement session line, no product bytes.

## Explicitly behind this block

`long` (coupled to the `defstruct/packed` restart), the parity pilot
itself (waits on the ship-builder version decision, 1.3), and everything
in the parked-items register whose reopening condition has not fired.
The resident geometry stays closed; every candidate above prices itself
in Bank 2, overlays or cold phases.
