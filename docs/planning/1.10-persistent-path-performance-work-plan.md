# 1.10 work plan — persistent-definition path performance

Status: **host block complete 2026-08-07** (owner direction decision: a long
autonomous host block). Candidate freight is retained for the next ordinary
release block; no delivery, link, device, or release claim is made here.

## The one sentence

Cut the measured cost of the persistent-definition path — today
~788 priced seconds for the defstruct sequence, dominated by 26,113
window events and nine append cycles — host-first, with the exact
Phase-A reconstruction machinery as the ruler, and no device or
release claim anywhere in the block.

## The evidence base (all bound, all green)

The 1.6 Phase-A reconstruction (11 forms, 9 persistent appends,
12,310 initial windows, 13,803 refills, 199,573 VM instructions,
byteidentical receipts, self-reconstructing gate) and the completed
duration pricing (26,995 frames + 5.488 s VM term → 788 s bound).
These numbers are the baseline; every claimed improvement is a
delta against them, recomputed by the same machinery.

## Candidate levers (priced first, then chosen — not all pursued)

1. **Window-event reduction**: emission locality (order code objects
   to minimize cross-window transfers), window-size/geometry within
   existing contracts, refill batching.
2. **Append-cycle cost**: batch the nine appends' shared phases where
   the C2J transaction contract allows — the contract itself is
   untouchable (publish-last, rollback correctness stay sacred).
3. **VM dispatch term**: only if 1+2 leave it dominant; no
   architecture change (the recursive VM stays; the tick-hook
   continuation plane is out of scope).

## Ground rules

- Host and micro-fixture work only; the reconstruction gate re-runs
  on every change; the pricing recomputes with named inputs.
- **Correctness gates are the walls**: all existing equivalence,
  journal, rollback, ownership and surface gates stay green at every
  step; a lever that dims any of them is rejected, not negotiated.
- Zero resident bytes (the closed geometry stands); Bank-2 budget
  changes priced explicitly.
- No release claim, no device contact, no link numbers. The device
  proof of any improvement belongs to the next release block's
  ritual, alongside the deferred comfort freight.
- Autonomy profile: Codex runs phase after phase without owner
  halts; reviewer acceptances are asynchronous. **The single owner
  touchpoint is the closing summary** — priced levers, achieved
  deltas, and the release-block recommendation.

## Success criterion

A recomputed priced bound for the full defstruct sequence
**meaningfully below the 180-second observation window** would be the
headline (the historical window becomes sufficient); any honest
material reduction with named deltas is a win. If pricing shows no
lever reaches material effect without touching sacred contracts, the
block closes with that finding — a truthful no is a valid result.

## Executed phases

### A — align the ruler and price every lever

The 1.6 receipt was replayed without changing its 788-second full-sequence
authority.  The accounting also separates the one-time resolver from the
clock that actually began after `(defstruct point x y)` was submitted:

| lane | windows | VM instructions | priced floor |
|---|---:|---:|---:|
| full Link-82 sequence | 26,113 | 199,573 | 788 s |

This split is not a cheaper replacement baseline.  It records that the

The non-window levers cannot close the gap.  Removing eight of nine append
cycles in an impossible best case would still price at 195 seconds after the
implemented candidate; removing the complete ordinary-VM dispatch charge
would still price at 216 seconds.  A larger VM code window consumes resident
state and therefore fails this charter before implementation.

### B — factor generated bodies into one Bank-2 truth

The selected lever keeps nine independently publish-last definitions and the
existing rollback transaction.  Predicate, copy, reader, setter, and
functional-update semantics now live once in the defstruct Bank-2 library;
the generated persistent definitions are small call wrappers.  Setf-place
registration similarly compiles one shared registration loop while retaining
begin/commit/abort and publish-last behavior.

The integration suite grew from 9 to 14 cases.  It separately proves tag
semantics, copy-spine independence, non-destructive functional updates,
successful publish-last registration, and conflict rollback.  The complete
generated-definition payload shrinks from 237 to 182 bytes.

### D — freight and rejection closure

The candidate adds 116 Bank-2 code bytes, 35 directory bytes, and 130 bytes
to the complete external library image.  Resident delta is zero; the bound
18,238-byte Bank-2 headroom becomes 18,108 bytes and remains far above the
8,192-byte preservation floor.

Append batching is rejected because its theoretical maximum remains above
180 seconds and real batching would renegotiate per-definition visibility and
rollback.  VM-dispatch work is not pursued because even erasing its entire
price is non-material to the remaining gap.  A compiler-carrier-wide rewrite
could attack the shared compiler/prelude helpers that now dominate, but that
is cross-surface compiler freight and needs its own carrier-equivalence and
release-cycle authority; it is not smuggled into this library-local block.

### E — closing disposition

The material-reduction success criterion is met; the under-180 headline is
not.  The permanent gate reconstructs the candidate, recomputes both pricing
lanes, executes 14 integration cases, and rejects 22 scope, semantics,
transaction, accounting, freight, and overclaim mutations.

Recommendation: carry this Bank-2 defstruct factoring into the next ordinary
release block beside the completed comfort freight and the editor
known-issue correction.  That block owns normal packaging, product/link, and
device acceptance.  If sub-180 remains a priority after that, commission a
separate compiler-carrier locality block; neither append batching nor the
priced VM-dispatch term can close the remaining 38-second gap.
