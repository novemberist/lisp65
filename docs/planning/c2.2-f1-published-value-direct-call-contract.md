# C2.2 F1 — Published Value Direct-Call Contract

Status: product-shaped probe candidate, hardware not run
Date: 2026-07-27
Baseline: promoted v1.2.0 / canonical C2-lite product

## Decision

`lcc-run` may bypass compilation, append, publication, and rollback when the
top-level form is a proper call to a currently published bytecode entry and
every argument form is already a value:

- a Fixnum;
- a String;
- `nil` or `t`; or
- an exact unary `(quote value)` form.

The established nullary path remains a direct `funcall`. An admitted n-ary
form constructs the corresponding value list and enters the same published
function through `apply`.

Variables, nested calls, special forms, macros, primitives, undefined
operators, malformed quotes, improper calls, and every other compound
argument form retain the complete `%c2-compile-form` → `lcc-install`
transaction.

## Arity truth

The direct-call guard does not maintain an arity table. The published
CodeObject header and `vm_arity_accepts` remain the only authority:

- fixed arity is admitted;
- `&optional` and `&rest` are admitted when the value-form guard passes;
- wrong arity is rejected by the ordinary VM status before the target body
  runs.

Restricting the Lisp guard to a second fixed-arity registry would duplicate
metadata and could not cover session-created entries without new mutable
state. This contract therefore restricts *argument evaluation*, where a proof
is needed, rather than duplicating target metadata.

## Semantic boundary

The admitted forms need no evaluation work beyond value extraction. Exact
`quote` contributes its single payload; all other admitted objects pass
unchanged. The resulting arguments are observationally identical to the
compiler path. No claim is made for a call containing a variable, nested
expression, or effectful form.

Generation, function-cell, strict-arity, status precedence, journal,
rollback, wipe, and publish-last rules are unchanged. F1 adds no resident
state byte, transaction byte, root, or native dispatcher.

## Required proof

The permanent host gate must cover:

1. nullary regression;
2. fixed-arity Fixnum and quoted-value calls;
3. optional and rest arity under the CodeObject authority;
4. direct wrong-arity rejection;
5. compiler fallback for every excluded shape;
6. Direct-vs-Compiler result identity for every admitted value class;
7. mutations that widen the value domain, bypass conversion, substitute a
   private arity truth, or alter the fallback.

The product-shaped probe must attribute all added bytes to Bank 2, show zero
resident/native delta, rerun the C2D-v6 one-emitter and root-surrogate gates,
and close the full WPLTO map before Halt #2. Hardware latency remains
unclaimed until the bundled S1 session.
