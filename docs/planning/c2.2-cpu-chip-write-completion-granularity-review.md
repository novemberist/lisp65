There is no residual unattributed growth.  The equality, poisoned readback and

The complete write inventory adds a fact missing from the first draft:
publication also writes the Bank-5 symbol pool, name-offset, value and
function-cell domains.  `publish_plan_resolve` interns names before the
header; `publish_exports` changes function cells after it.  Rollback restores
the latter.  These writes use the same ordered DMA seam as C2D and C2J.

## Proposed contract shape

There are exactly two amortized **transaction-data** boundaries:

1. pre-header: drain all preceding writes and prove the touched Bank-2 and
   Bank-5 target spans once, then content-prove and publish the header;
2. pre-rollback: drain all forward writes and prove the touched spans once
   before export restoration, header restoration or any wipe begins.

They do not make the journal bookends optional:

- C2J ACTIVE must itself be content-converged before the first mutation.
- C2J CLEAR must itself be content-converged last.  It is also the ordered
  tail fence for post-header publication writes on success and for all
  restoration writes on rollback.

Thus the proposal is **two shared data barriers plus two journal bookends**,
not four copies of the general barrier.  One cold body can implement both data
barriers, selected through existing scratch and invoked only by the resident
serial driver.  Writers merely submit and update a bounded touched-span
description.  No overlay calls another overlay.

Interpreting “exactly two points” as only two physical proofs in the whole
transaction would weaken the established journal contract.  A nonconverged
ACTIVE record can be absent when rollback needs it; a late CLEAR can survive
return or erase the following transaction's ACTIVE record.

## Class-C question

Does “completion proof at exactly two points” mean exactly two amortized
transaction-data barriers, while C2J ACTIVE and C2J CLEAR remain mandatory,
independently content-converged journal bookends?

The recommendation is **yes**.  With that answer the next probe can first
remove all nine private proof bodies, measure the one common cold body, and
only then draw the C2J, publish/clear and rollback-finalize slice boundaries.
The separate 28-byte Bank-0 text deficit remains fund currency and receives
no credit from this analysis.
