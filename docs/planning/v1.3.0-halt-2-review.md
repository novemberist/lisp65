## Outcome first

v1.3.0 is release-ready. It is the first release centered on programs that
leave the Workbench: `(ship ...)` produces a standalone bootable D81 with a
cold stager, evaluator-free runtime, required library closure and compiled
program. Four programs exercise the real Ship path. The interactive sample
was booted on the accepted MEGA65, read `Ada` from the physical keyboard and
displayed `Hello, Ada!`; no virtual key injection supplied that result.

`q` family. The earlier `fx` spelling is deliberately renamed before the
first advertised release. The Workbench editor's measured average typing
cost falls from about 78 to about 24 raster frames per key. The visible banner
is `WORKBENCH 1.3.0`.

[`docs/releases/1.3.0.md`](../releases/1.3.0.md).

RUN/STOP seam is not claimed by this release.
