# 1.8 work plan — full memory-map ownership

Status: **Phase B complete 2026-08-04**; exactly one honest layout fits and
is auto-selected, so Halt 1 is omitted and Phase C is open by the accepted

## The one sentence

The generated linker script places every ordinary output section —
rodata, data, BSS, `.noinit` — at contract VMAs with fail-closed
capacity checks, completing the ownership programme: after this block
the entire product memory map is contract-owned and a product card can
fail only on honest capacity, never on placement.

## Inherited, binding substrate

The 1.5/1.7 ownership contracts and live gates (stack arena, overlay
floor `$C354`, MAP window and ABI, 98-byte facade, 874-byte assembly
far body at `$78B2` with its permanent C-equivalence gate, ZP map
`$87..$89`), the 72-region/7-family state inventory, and the bound red
cards of 1.5 Phase D and 1.7 Halt 2 as the failure authorities.

## Scope

- Contract VMAs and capacities for the ordinary rodata/data/BSS/
  `.noinit` chain, derived from the bound inventory — including the
  665/663-byte displacement families the red card names.
- Heap start and overlay floor asserted against the completed chain
  (both are already contract constants; the chain must respect them,
  the overlay must never sit under the live heap).
- The permanent gate inspects the generated linker script and the
  linked final ELF; expected addresses come from contract constants,
  never from the source under test; simultaneous-live rule on every
  fit claim.

## Bounds

- The 1.5/1.7 rejection rules verbatim (no padding, repin, partition
  or assert candidates; no semantics changes).
- Host and micro-ELF first; **one** product-shaped WPLTO card; its
  green reopens the chain (1.5 Halt 2 → parity pilot → Link 91), its
  red parks the whole ownership programme with a complete final
  inventory — there is no 1.9 placement block, because after full-map
  ownership no unowned placement layer remains.
- Two owner halts: contract choice (if real alternatives exist) and
  the card/reopening decision.

## Phase order

**A → B → Halt 1 only if B has more than one honest row → C → D →
Halt 2.** A and B are read-only inventory/contract work. C may build
micro ELFs and relink the already-bound 1.7 LTO object as an explicitly
non-promotable fixture, but may not compile a product or consume WPLTO.
D consumes at most one fresh product-shaped WPLTO. A linker/tool stop
before compiler invocation does not consume the card; once WPLTO has
started, no retry exists.

The end condition is structural, not chronological: after C, every
allocatable product input section must resolve to exactly one contract
owner. An unknown allocatable section is a full-map failure, not the
seed of a later placement block.

output in the still-inherited chain:

  ordinary `.bss`, and ordinary `.noinit`;
- the extracted `.noinit..Lstatic_stack` input as the already-owned
  compiler-stack family, never a second ordinary-noinit tenant;
- the CRT load/zero/preserve symbols and ranges for data, BSS and
  noinit; and
- `__heap_start`, the named gap before it, the overlay floor `$C354`,
  the actual overlay VMA and the complete simultaneous-live relation.

The inventory reconciles byte sums, alignment and VMA/LMA for every
member against both the failed map and the LTO object. It also closes
the contradiction exposed by the 1.7 card: after the six-byte static
stack is extracted to `$C074`, ordinary `.noinit` may not still claim
the same six bytes at `$C34D`. If its demand is zero, the old interval

## Phase B — define and price the full-map contract

Using only Phase-A facts and existing independent fixed addresses,
define the complete output ledger. The contract owns starts,
capacities, order, alignment and initialization semantics for ordinary
rodata → verifier bindings → data → BSS, followed by the already-owned
convergence/stack/fixed-state plane, ordinary noinit or its explicit
empty owner, heap boundary and runtime overlay.

The generated-linker mechanism must **replace ownership of the
inherited output stanzas**, not append another `INSERT AFTER` layer.
Each allocatable input has exactly one wildcard consumer and each
ordinary output exists exactly once. Data retains a valid copy
source/destination relation, BSS remains wholly in the CRT zero range,
noinit remains wholly outside it, and the extracted compiler stack is
neither copied nor zeroed as ordinary state. Heap and overlay constants
are asserted against the completed chain; an overlay below the live
heap is unrepresentable.

At most two rows may be priced, and only when they differ in real
ordering or initialization semantics. Moving a wall to current output,
padding a gap, duplicating noinit, changing alignment to gain bytes,
partition steering, or adding assertions without owning output
placement is not a row. All families are priced simultaneously with
the 98-B facade, 874-B far body, ZP, convergence state, stack and fixed
C2 state.

If one row fits, the charter selects it and there is no ceremonial
Halt 1. If several fit, Halt 1 chooses. If none fits, Halt 1 receives
the final-capacity park packet and C/D do not run; a known impossible
map is not sent through WPLTO for theatre.

## Phase C — implement full-map ownership, host-first

Implement exactly the selected B row in the canonical generated linker
source. The permanent gate has three independent layers:

1. **Linker-source closure:** expected addresses come from the Phase-B
   contract, never the generated script. Every Phase-A input is routed
   once, no allocatable orphan remains, output order and capacity are
   explicit, and none of the old inherited stanzas can consume the same
   inputs.
2. **Execution semantics:** a host/micro fixture seeds distinct bytes
   in data, BSS, ordinary noinit and the compiler-stack arena, then
   executes the real startup range logic. Data is copied, all and only
   BSS is zeroed, noinit is preserved, the stack is independently
   owned, and heap/overlay sentinels survive. Each class reports a
   non-zero execution witness.
3. **Artifact truth:** two clean micro links plus two links of the
   already SHA-bound 1.7 LTO object through the new script are
   byteidentical within their pair. The product-object replay is a
   non-promotable linker fixture — zero compiles, zero WPLTO — and must
   place the complete simultaneous-live map at the contract VMAs with
   all existing 1.5/1.7 gates still green.

Mutations reject missing `.rodata.*` capture, section reordering, wrong
alignment, data LMA/VMA alias drift, incomplete BSS zero range, noinit
zeroing, static-stack double ownership, a fake padding tenant, derived
heap/floor addresses, overlay below heap, an unknown allocatable input
and a source-derived address oracle. The gate is permanent in
`check-source` with its execution count before D is permitted.

No product source or semantics change is allowed in C. Only linker
ownership, its independent contract/gate and evidence may change.
