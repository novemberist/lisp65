# Block 2.5 public-surface domain audit

Status: **complete — read-only; no repair and no product byte**.

## Population and execution authority

The population is exactly the 139 rows of the public metadata index.  Each row
owns six cells: number, string, symbol, `nil`, proper list and function
designator, for 834 observations in total.  The argument object is repeated
across the required argument vector; consequently heterogeneous functions may
reject every representative.  This is an out-of-domain stability matrix, not a
positive conformance suite.

The executor materializes the six images of the v1.9.0 static plane and invokes
their real code objects.  CALLPRIM dispatch is constrained by the delivery
table derived from the released v1.9.0 ELF: 84 table entries, with IDs 1, 2,
12, 26, 27 and 40 tombstoned.  Thus a host-only primitive that the product did
not ship cannot make a cell green.

## Result

| Classification | Cells |
|---|---:|
| error raised | 483 |
| documented permissive | 179 |
| silently wrong | 172 |

The 172 silent cells belong to 41 public names.  They are findings, not repairs.
The sharpest resident examples are `car` and `cdr`: both return values for
number, string, symbol and function operands instead of rejecting them.
`length`, `append`, numeric comparisons and several library sequence walkers
show the same family in library form.  In particular, `length` observes a
three-character string as one list cell; callers that mean strings must use
`string-length`.

The classifications do not by themselves authorize changing Common-Lisp-like
permissiveness or error compatibility.  Library sequence-walk repairs can be
priced separately; changing `car`/`cdr` remains owner-bound as the work plan
requires.

## Permanent contract

`config/public-surface-domain-contract.json` records both sides of every cell,
including the specific target result or error.  The permanent gate rejects:

- a public symbol without a domain row;
- removal of an existing row;
- a classification/result/error flip; and
- execution against an invented delivered primitive (the CALLPRIM-12
  false-green shape).

Implementation: `tools/host-lisp/public_surface_domain_audit.py`, reachable
from `check-source`.  The product sources and released evidence are unchanged.
