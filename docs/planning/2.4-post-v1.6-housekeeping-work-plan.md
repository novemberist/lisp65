## Work items

1. **Rulebook consolidation.** The input-fidelity era minted more
   permanent rules than any before it. Harvest them from the v1.6 plan
   into `docs/reference/gate-and-tool-register.md`, each with owning gate
   and biting mutation: the instrument law (bound origin, neutrality,
   removal default), single-owner-per-shared-resource with defined-state
   handoff, claims-prove-on-the-final-world and
   the-claim-chain-ends-at-the-shipped-byte, phase-owned guards and
   outputs, enforce-what-you-record, a-forecast-is-a-floor,
   derived-not-enumerated coverage (populations, features, mutations,
   callers, components), domain-aware addresses in overlapping arenas,
   declared-width state cells, diagnostic-freight-in-diagnostic-worlds,
   the anti-rabbit-hole triage form.
2. **Plan sealing.** The v1.6 freight plan (10,000+ lines) seals as
   historical with a closing entry; v1.7 starts lean. The finish plan's
   outcome (descope, reset bar) is summarized in the seal.
3. **Register grooming.** Close delivered rows (cursor navigation, the
   five shipped fixes); move the Comfort/capture/prompt/display rows to a
   consolidated **v1.7 pre-plan row set** with the sealed `(repl)` fault
   file as bound starting evidence; update every capacity watch to the
   post-descope world (105/1,413 symbols/names; text, far-service, E000,
   MAP-arena figures re-derived); classify the witness/latch tooling as
   historical.
4. **Docs alignment.** Architecture overview and user guide catch up:
   cursor navigation, the backstop (an error returns to the prompt),
   verified boot refill, queue ownership. Known-issues: v1.5 silent-DMA
   entry marked fixed-in-1.6.0; fast-typing loss entry checked for
   current wording.
5. **Evidence and repo hygiene.** Evidence index re-verified; the v1.6
   era's first-red artifacts archived; branch inventory checked (releases
   land on main — verify the standing rule held); SD-card note for the
   owner (released set plus none).
6. **Gate runtime re-measured** (last: 15 min 30 s at ~2,000 lines; now
   ~2,300 lines) — measured, not guessed; tiering only if the number
   demands it.
7. **v1.7 pre-plan.** One lean document gathering the agenda with rough
   order: Comfort REPL complete (capture, hybrid, prompt, display
   ownership — starting from the sealed fault file), INIT.L65 with the
   canonical prompt swap, matcher, blink cursor, IDE service time,
   symbol-economy study (re-scoped: the pressure is gone, the study
   becomes optional), boot snapshot, items 3–4 heritage, key-event
   residual. No commissioning — inventory and order only, for the owner
   to cut.
