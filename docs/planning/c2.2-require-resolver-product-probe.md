# C2.2 `require` resolver — product-shaped WPLTO probe

Status: Class-C probe authorized; no product link and no hardware run are
authorized by this document.

The target resolver keeps the host-first semantics but replaces its two
surrogates with product truth.  Library identity is the canonical combined
CRC32 already emitted in the one-record L65S-v4 artifact and published in the
generation-bound C2D-v6 image row.  Loaded state is therefore derived from
C2D; no `*loaded-libs*`-style registry is introduced for `require`.

## Cut

The Lisp dependency/index resolver is Bank-2 freight.  Its only native
question surface is private Prim-ID 67, `%c2d-byte(lo hi)`.  Both operands are
strict bytes; their little-endian address must lie in the published
33,840-byte C2D plane; the primitive reads exactly one byte through the
already resident `c2_stream_c2d_read` and returns a Fixnum.  It is not exported
as public API.  The former `%disk-load-lib` string command, caller-owned query
context, typed result protocol and append-overlay roundtrip are removed.
Ordinary filename queries retain their historical six-image lookup.  There is
no new resident state, vector, Session record or format width.

The first authorized form put identity scans, persistent/transient-front
derivation and all six capacity decisions in native C.  WPLTO measured that
private resolver at 3,491 bytes and stopped the existing append-image slice at
4,297/1,792 bytes.  That First Red is retained as evidence, not compressed or
split: it proved that orchestration lived in the wrong language.

The successor therefore makes the native surface deliberately ignorant.  It
does not know an L65I identity, dependency, active count, frontier or capacity
currency.  Bank-2 Lisp walks the C2D header and rows, rejects foreign or
duplicate persistent identities, proves the contiguous persistent code edge,
derives the transient directory and code edges, and closes the aggregate
six-currency preflight.  The existing append transaction remains the
authoritative mutation-time recheck.

The first private-byte implementation hand-expanded arity, type and byte
range beside the already resident `vm_byte_args` validator.  WPLTO measured
that duplicate proof logic as +252 bytes in `vm_callprim` and +256 resident
text bytes overall.  The authorized successor consumes
`vm_byte_args(a,n,2)` once and retains only address construction, the
published-plane bound, the one-byte C2D read and the typed result.  Its hard
acceptance ceiling is +58 resident text bytes against Link 67, leaving the
32-byte LTO-noise reserve intact.  Missing that ceiling selects the eighth
non-LTO assembler leaf directly; no further C-form iteration is authorized.
The measured C successor added 168 resident text bytes and therefore selected
that fallback.  `vm_c2d_byte` is a named, sized, non-LTO function in the
existing `reopen_gap1` pocket of the owned C2 window; case 67 has one
C-to-ASM edge, and the leaf owns the
address construction, published bound, single canonical reader edge and tagged
result after case 67 consumes the shared strict two-byte `vm_byte_args` proof.
It reuses the expiring CALLPRIM argument cell as the one-byte destination, so
it introduces no resident scratch or second truth.
The preferred independent `LDA #0 / STA __rc5` high-byte form measured two
bytes too large for the immutable 54-byte E000 floor.  The authorized fallback
therefore materializes `$0001` with an adjacent `LDZ #0 / STZ __rc5` pair.
Because 45GS02 `STZ` stores the live Z register, the permanent source-derived
dominance gate proves this adjacency and rejects the nonzero-Z regression.

## L65I-v1

`L65INDEX` is one generated, non-evaluated D81 file.  It has a 32-byte header
and fixed 48-byte rows.  The header binds its first 17 bytes with CRC16/CCITT;
each row binds bytes 0–44 with the same CRC; the header separately binds all
complete rows with CRC16 and CRC32.  A row binds canonical name, D81
track/sector, the real L65S combined CRC, dependency ordinals and exact W1
deltas.  Unknown versions, sources, ordinals or nonzero reserved bytes fail
closed.

The generation-lifetime index lock is not a loaded registry.  It freezes one
index identity for the current Lisp session so a second resolution cannot
silently reinterpret names.  Actual loaded truth remains the set of
persistent, current-generation C2D identities.  No Lisp shadow list is
materialized, and no static Bank-2 byte count is copied into Lisp: each
operation first derives the immutable static end from C2D slots 0--5, then
walks the persistent rows, requires every active identity to occur exactly
once in the locked index, and proves its Bank-2 coordinate and measured L65I
code length.  This rejects stale, foreign, duplicate and
same-name/different-identity worlds.

## Probe boundary

The product-shaped probe must show all of the following in one WPLTO:

- exact Bank-2 freight and C2D deltas from the single emitter;
- the private C2D-byte primitive in the linked CALLPRIM dispatcher, with zero
  native resolver decisions, no string/query protocol, no overlay roundtrip
  and no new Session catalog record;
- Bank-2 orchestration delta and linked primitive delta attributed separately;
- total resident `.text` delta no greater than 58 bytes, with at least the
  32-byte noise reserve remaining;
- Link-67 floors and anchors unchanged and all five resident walls positive;
- the existing 1,792-byte slice cap and 64-KiB Session aggregate held;
- binary-index, dependency, idempotence, capacity, mutation and cutpoint gates
  green.

Any wall crossing, floor/anchor movement, new catalog record, format widening
or second resolver truth is a First Red and returns to Class C.  The small
resident delta of the private primitive is measured rather than prepaid.  A
green probe is not a link or a hardware claim; it is the separate-review
candidate beneath `(require 'defstruct)`.
