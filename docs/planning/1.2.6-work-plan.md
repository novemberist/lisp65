## The one sentence

Typing must stop stalling: the measured mechanism — 169.26 allocated
cells and 0.882 derived collections per serial key, up to four
collections in one wrap key against an 89-frame collection envelope — is
repaired at the **renderer allocation shape**, not at the collector.

## Ground rules (unchanged) and pre-registered stop rules

Host-first, receipts with execution witnesses, dependency-sharp first
red, no inherited green, substitutive-never-additive, resident geometry
closed. From the B3 menu, binding:

1. **No resident delta and no Session correctness-phase refusion.** The
   old G1 three-service carrier (399 B over geometry) is not silently
   resurrected.
2. **Host allocation gate before any product link.**
3. A smaller `room`-first instrument may join **only if** it fits
   without touching rollback, publication or journal phases — it earns
   its own capacity map or it stays out.

## Phase A — Allocation contract (paper, then gate)

A1. **Per-key allocation ceiling contract**: name the budget per
    keystroke class (plain key, wrap key, scroll key) and the derived
    collections-per-key ceiling (target: **no key class derives ≥ 1
    collection on average; no single key contains a multi-collection
    burst**).
A2. **Permanent host accounting lane**: the existing 80-key lane becomes
    a gate with the ceiling as its threshold and an execution witness —
    red on any key class exceeding its budget. This is the class closer
    for "the flagship surface quietly regressed into unusable".
→ No halt.

## Phase B — Renderer allocation shape (Bank 2, host-first)

B1. **Eliminate the per-render typed-line list materialization** — the
    attributed dominant allocator. Rework the redisplay path to reuse
    its line carriers (the buffer type exists; zero heap churn per
    repaint is the design target, small constant churn the fallback).
B2. **Input coalescing, made coherent**: the measured 10-key coalescing
    already cuts to 47.62 cells/key; keep it as a *mechanism with a
    contract* (no reordering visible to the user, RUN/STOP never
    coalesced) rather than an accident of measurement.
B3. Equivalence lanes + the A2 gate green; **one WPLTO**, walls named.
→ No halt if the walls hold (243/54/2/137/50/113 B all unchanged —
   Bank-2-only work).

D2. `(time)`-based spot checks on wrap/scroll keys.

    smoke inherited from the acceptance suite.
→ **Class-C halt #1**: measurements on one table; owner sees latency and
   dropped-input numbers against the "not usable" report.
