# v1.2.1 release plan

Status: **published 2026-07-29**

Candidate: Link 77 (`while`, `random`, interrupt-ownership policy,
`require` fast path, boot-only CRC relocation).
Baseline for comparison: released v1.2.0, product set `37998ce7…941d`,
seal `c2-lite-r6-g6-hardware-acceptance-19aa835`.

## Ground rules

Unchanged: host-first, receipts, SHA binding, claim hygiene, first-red
discipline (dependency-sharp in bundled sessions), no inherited green.
Device demand is collected into the acceptance chain itself; no separate
diagnostic trips.

## Phase A — Acceptance chain on Link 77

A1. **Pre-chain hygiene.** Fresh full equivalence chain with the execution
    witness (case count non-zero and as expected); document index green;
    receipt tree and promotion register cross-checked.
A2. **Cross-invariant delta review.** The 25-row matrix was dispositioned
    against Link 57. Re-run only the rows the Link-77 delta can touch —
    interrupt ownership (D1/D2/D3), non-local exits and the abort landing
    (B1/B2), and anything the `while` backedge or the `require` fast path
    reaches. Rows outside the delta keep their disposition **with an
    explicit statement that they were not re-derived**; no silent
    inheritance.
A3. **R4/R5/R6/G5/G6 fresh on the Link-77 source successor**,
    single-device value strings, `remote_head` seals per
    Promotion-v3/G6-v2. No green is inherited from the v1.2.0 chain.
    The repeatable candidate rebuild is deliberately a new identity:
    the post-Link-77 EXT-heap host lane compiles out on the target but is
    still part of the source-bound profile hash. It must therefore pass the
    fresh chain under its own bytes; the Link-77 hardware receipt is feature
    history, not an acceptance claim for the rebuilt candidate.
→ **Class-C halt A:** chain results reviewed before promotion.

## Phase B — Release preparation (paper/host only)

B1. **Release notes for v1.2.1.** Content, honestly scoped:
    - `while` — the committed non-local-exit primitive, native special form
      in all four execution views; document the **streamed-backedge
      property** (a loop whose backedge crosses a code-window boundary pays
      one window refill per iteration — keep tight loops small).
    - `random` — lagged Fibonacci (24,55), `(random n)` with rejection
      sampling, explicit `(random-seed k)` for reproducible runs, hardware
      entropy seeding; delivered in the base composition.
    - Interrupt-ownership hardening — Ethernet, Auto-IEC and audio DMA are
      now masked; raster remains the sole owned source.
    - `require` fast path — repeat resolution costs ~98 % fewer VM steps.
    - Known issues, unchanged and newly added (see B2).
B2. **Known-issues delta.** Carry forward the v1.2.0 entries and add:
    - **Interrupt-capable cartridges are outside the supported profile.**
      A single foreign IRQ per raster episode is tolerated; a storm
      fail-closes.
    - **Intermittent, unreproduced post-GC out-of-memory** observed once in
      a `while` allocation workload (Link 77 session); 1,200 allocations in
      the follow-up session ran clean. Conditions recorded, fixture kept.
    - **DIRMISS detail rendering** shows a truncated name. `symname` and the
      symbol read seam are exonerated; static attribution proves that the
      L65E consumer overwrites the correct pointer return with incidental
      A/X. The two-store correction is parked for v1.2.2 because the v1.2.1
      chain was already sealed.
    - `defstruct` and dynamic library freight remain parked (restart package
      unchanged).
B3. **Docs commit, index, push**, tag/refset ritual.
B4. **Public-repo sync** per §15c, including the clean-build gate that must
    reproduce the sealed product set from a fresh checkout.
→ **Class-C halt B:** owner reviews notes and gives the publish go. One
   decision. Nothing is pushed public before it.

**Phase-B disposition (2026-07-29):** B1/B2 are closed in the proposed
v1.2.1 notes and user-facing Known Issues. B3/B4 are closed: after the
one-word Halt-B authorization, public `main` and annotated tag `v1.2.1` were

## Phase C — Interleaved, autonomous (no halts)

C1. **DIRMISS renderer attribution, host/static only.** The read seam and
    `symname` are exonerated; finish the attribution in the L65E consumer.
    If a convicted one-liner results, it rides the release only if it lands
    before the chain starts — otherwise it waits for 1.2.2. Do not delay
    the release for it. **Closed:** the consumer overwrites `__rc2/__rc3`
    after `symname`; fix parked for v1.2.2.
C2. **Upstream bundle refresh:** add L11 (audio DMA is IRQ-capable in the
    pinned core, contrary to the published prose, with the VHDL line
    citation) to the owner's paste-ready bundle. **Closed.**
C3. Housekeeping: the queued `vm_string_arg_p` harness first red, receipt
    and index hygiene. **The source guard is fixed; final execution witness
    and index closure are part of the Halt-A package.**

## Explicitly out of scope

`defstruct` / dynamic library loading (parked), the GC envelope cut,
C2.3 items, the ship builder, and any capacity renegotiation. The terminal
geometry of the seal stands.
