line, accepted Cursor Left/Right, insertion and deletion directly at the
native prompt, and did not emit `*** reader: invalid token`. Explicit

green.

input rows. The visible oracle returned 7, and the stopped-state counters were

ring and the delivered editor consuming it across the forced collection.

projection of 111/1,473 is fully attributed: the final Block-A/B successor
