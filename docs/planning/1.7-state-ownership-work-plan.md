# 1.7 work plan — Bank-0/ZP state ownership

Status: **Halt 2 pending owner disposition** (Phase C green; the sole
Phase-D product card is red and consumed, 2026-08-04). Commissioned at the
1.6 Phase-D halt under the standing order.

## The one sentence

Bank-0 state (BSS/`.noinit`), ZP allocation and the far-service body
size stop being whole-product-optimizer accidents and become owned,
contracted quantities — so the 1.5 mapped-far-service row can pass its
product-shaped card and reopen the chain toward the parity library.

## The charter seed (from the 1.5 Halt-2 red)

Micro-fixtures obey contracts; the whole-product optimizer owns
placement until state itself has owners. The one Phase-D card failed
exactly there: BSS +1,089 B, ZP +2 B, `.noinit` drift 1,161 B,
overlay-floor drift 1,773 B, far body 1,433 vs contracted 1,499 B —
while every micro-ELF fixture and the 52-execution ownership gate
stayed green.

## Scope

- Named state arenas for BSS/`.noinit` families with contract VMAs and
  capacities (the state analogue of the proven 12-byte stack arena).
- An owned ZP allocation map with explicit owners and a fail-closed
  capacity check.
- Optimizer-independent far-body size: the mapped service body is
  KEEP-ed, sized and asserted as a contract constant, not an LTO
  outcome.
- The 1.5 ownership contract and gate are the substrate — extended,
  never weakened; the simultaneous-live rule binds every fit claim.

## Bounds

- Host and micro-ELF first; one product-shaped WPLTO card at the end,
  exactly one, per house discipline.
- No semantics changes, no partition/padding/assert candidates — the
  1.5 rejection rules apply verbatim.
- Success criterion, binding: the 1.5 Phase-D card configuration
  passes on owned state geometry — that green reopens 1.5 Halt 2, then
  the parity pilot, then Link 91.
- Two owner halts: geometry choice (if alternatives exist) and the
  card/reopening decision.

## Phase order

**A → B → Halt 1 (only if B has more than one honest row) → C → D → Halt 2.**
No phase creates a product identity before D.  A and B are artifact/contract
work; C may build host and micro-ELF fixtures; D consumes exactly one
product-shaped WPLTO card.  A red D cannot be relabelled as a narrower state
claim and cannot trigger an address-tuning retry.

- the complete failed-card simultaneous-live intervals, including ordinary

The receipt reconciles input-section byte sums with the failed map.  It names
gaps as gaps rather than silently allocating them, and reports overlaps and
capacity deficits rather than proposing a layout.  Mutations reject a missing
state family, duplicated ownership, a falsified Bank-0 deficit, a falsified ZP
deficit and an exact-size claim for the drifting far body.  No compile, source
annotation, linker regeneration, WPLTO or device contact occurs.

## Phase B — define and price owned arenas

Against A's complete inventory, write a v2 ownership contract whose expected
addresses are independent constants, never read from the linker source under
test.  It must give every state input exactly one semantic owner and exactly
one arena, then price the simultaneous-live set as a whole:

1. ordinary Bank-0 state arena(s), convergence state, compiler stack, fixed
   C2 state, heap start and overlay floor;
2. the complete ZP map, including every deliberate gap and the two
   convergence scratch bytes;
3. one optimizer-independent far-body ownership mechanism with exact code
   identity/size and a named Bank-2 capacity;
4. zeroing, initialization and preservation semantics for each arena across
   boot, session, append, overlay and fail-closed transitions.

At most three structural rows may be priced.  Assertion changes, padding,
compiler partition steering and a capacity wall moved to the current output
are not rows.  If exactly one row fits without semantic change, it is selected
by the charter and no ceremonial Halt 1 is needed; if several fit, Halt 1
chooses; if none fits, Halt 1 receives a park recommendation.

## Phase C — implement the selected ownership, host-first

Implement only the selected B row.  The permanent gate inspects the generated
linker and final linked micro-ELF, not source annotations.  Positive execution
must cover every A state input exactly once, zero/init semantics, stack shapes
3/4/6/12 with 13 failing closed, ZP at capacity and capacity+1, exact far-body
identity in two clean builds, invariant overlay floor `$C354`, and the existing
52-execution mapped-service ownership suite.  Mutations reject an orphaned or
double-owned state, an arena overlap, missing zero/init coverage, ZP overlap,
derived floor, optimizer-sized far body and source-derived oracle address.
The gate is in `check-source` with a non-zero execution witness before D.

## Phase D — the sole product-shaped card
