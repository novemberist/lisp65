# v1.2.2 release plan

Status: **published 2026-07-29**

Candidate: Link 78 (DIRMISS renderer fix; hardware-proven full name output).
Baseline: released v1.2.1, public main `bd8186d0…`, tag `f4b4fa0d…`.

## Scope

One user-visible correction. This is deliberately a small, honest release —
not a collection point. Nothing else is in the pipeline: `defstruct` is
permanently parked for this era, G1 (`gc`/`room`/`error`) is parked on
capacity, G3 is closed pending measurement.

## Ground rules

Unchanged: host-first, receipts, SHA binding, claim hygiene,
dependency-sharp first red, execution witnesses on every permanent check,
no inherited green. The rebuilt candidate passes the fresh chain under its
own bytes; earlier hardware receipts are feature history, not acceptance.

## Phase A — Acceptance chain on Link 78

A1. **Pre-chain hygiene.** Fresh full equivalence chain with execution
    witness, document index, receipt tree, promotion register cross-check.
A2. **Cross-invariant delta review.** Re-derive only the rows the Link-78
    delta can touch — the L65E consumer / error-rendering path. All other
    rows keep their disposition **with an explicit statement that they were
    not re-derived**.
A3. **R4/R5/R6/G5/G6 fresh**, single-device value strings, `remote_head`
    seals per Promotion-v3/G6-v2.
A4. **The G2 measurement rides the G5 session as extra rows** — no separate
    device contact:
    - `(dotimes (i 1000) (boundp '*g*))` and
      `(dotimes (i 1000) (symbol-value '*g*))`, per the prepared session
      contract (the two bound-carrier forms differ in exactly one byte:
      `CALLPRIM 57` vs `CALLPRIM 19`).
    - Result line must report: `Δ frames/1000`, `Δ/1000 frames per read`,
      `Δ×20 µs per read`, and `projected-480 = Δ×480/1000 frames`.
    - Pre-registered threshold: **≥ 44.5 frames** names the Bank-5 symbol
      path as the dominant GC lever; below that, no GC cut is authorized.
    - The constant applies directly to the 2-byte `vm_dma` paths
      (`symval_get`, `nameoff_get`, `symfn_ext_get`); for `symname` bulk
      reads and prim 67 it is **reference only** — different transport form.
    - These rows are measurement, not acceptance criteria: they cannot make
      the chain red, and a red chain row does not invalidate them.
→ **Class-C halt A:** chain results plus the measurement reviewed together.

Owner disposition: **accepted 2026-07-29**. G5 passed 9/9, G6 passed 5/5,
R6 double-packed byte-identically, and the isolated seal verified 540 files.
The G2 difference was 0 frames per 1,000 measured reads; the pre-registered
44.5-frame threshold was not met, so Phase C remains closed.

## Phase B — Release preparation (paper/host only)

B1. **Release notes for v1.2.2.** Short and exact:
    - Fixed: undefined-function errors now report the complete symbol name.
      Previously the name was truncated (the reported symbol could appear as
      a single character), which made diagnosing user code unnecessarily
      hard.
    - No other product change.
B2. **Known-issues delta.** Remove the DIRMISS entry; carry everything else
    forward unchanged (cartridge exclusion, intermittent unreproduced
    post-GC OOM, parked `defstruct`/dynamic library freight). Add, if the
    measurement warrants it, a factual note on GC cost — measured, not
    estimated.
B3. **Docs commit, index, push**, tag/refset ritual.
B4. **Public-repo sync** per §15c including the clean-build gate that must
    reproduce the sealed product set from a fresh checkout.
→ **Class-C halt B:** owner reviews notes and gives the publish go.

Prepared result: a local DCO-signed public candidate, two varied fresh
clean-builds reproducing the exact 19-role accepted product set, and four
deterministically packed release assets. No public ref, tag, or release was
changed during preparation. See
[the Halt-B review](v1.2.2-halt-b-review.md).

Owner disposition: **Publish**, completed 2026-07-29. Public `main`, annotated
tag `v1.2.2`, the five-asset release, and the downloaded readback are bound in
the final publication receipt.

## Phase C — After the measurement (no work authorized here)

If the threshold is met, a named GC lever exists: the symbol-value root
plane is read one 2-byte DMA at a time while the C2D root plane already uses
32-byte block reads. A cut would follow that existing precedent. Whether it
is commissioned at all is a separate owner decision **after** v1.2.2 ships;
this plan authorizes no optimisation.

## Explicitly out of scope

`defstruct`, dynamic library freight, the `gc`/`room`/`error` trio, C2.3
items, the ship builder, capacity renegotiation. The resident geometry is
closed: any future functionality lives in Bank 2, overlays or cold phases.
