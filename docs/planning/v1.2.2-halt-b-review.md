## What the release says

The proposed [v1.2.2 release notes](../releases/1.2.2.md) make one product
claim: undefined-function errors once again report the complete symbol name.
Earlier 1.2 releases could shorten the displayed name to one character or pad
it with spaces. There is no other product change.

The DIRMISS display item is removed from Known Issues. All other user-facing
boundaries are carried forward:

- use the Freezer only while the evaluator is idle;
- do not use an interrupt-generating cartridge while lisp65 runs;
- preserve the exact workload if the intermittent post-GC out-of-memory
  symptom returns; and
- `defstruct` and dynamic-package freight are not delivered.

The informative G2 result is recorded without turning it into a GC claim:
1,000 measured 2-byte symbol-value reads added zero frames. Projecting the
measurement across 480 reads accounts for less than half a frame of the
isolated 89-frame collection envelope. The Bank-5 symbol-value path is
therefore not the dominant term; that dominant term remains unattributed.

no partial result from a failed build was inherited.
