## Release theme

v1.9.0 is the *interactive completion* release: the input path becomes
lossless end to end, and the native prompt finally owns the editor. The
freight below is ordered; blocks A and B carry the release, everything
after them ships only if it is accepted in time. The standing cut rule
applies: on release day, what is accepted ships.

## Block A — far-service relocation + native capture client

The pre-registered opener (16dc1eb7). One combined card:

1. Apply the sealed page-congruent r10 far-service placement (`$28000`
   tuple world, A=$80/X=$82, far service `$2F8B2..$2FE82`, product-cold
   behind it, congruence gap and end reserve as named owners). The
   tuple=LOADADDR gate and MAP $100-congruence law already exist.
2. Re-run the already-written native arm/disarm client card on top: the
   line editor arms capture at `read-line` entry, disarms on return —
   sealed Phase-1b arm/disarm owner byte-identical, queue single owner,
   RUN/STOP matrix latch.
3. Walls, measured not inherited: 94/94 lossless, zero drops,
   normalization, responsiveness ≥ 25% margin, composed owner map,
   armed-lifecycle pre-media preflight (final ELF proves the ring arms
   on the delivered `read-line` path).

Budget: one WPLTO + one product link (a second link only by decision
card). Exit: hardware acceptance retires the v1.5 fast-typing Known
Issue. This block alone justifies the release.

## Block B — the native prompt gets the editor

The v1.8 endgame attribution proved the native `lisp65>` prompt never
uses the Bank-2 editor; Cursor-Left errors pre-parse (Known Issue,
`docs/known-issues.md:73`). Two priced variants, decision card picks:

- **B-light:** the native C loop routes through the public Lisp
  `read-line` when the editor world is present (boot-time binding via
  the INIT seam is acceptable), C fallback unchanged otherwise. Small,
  no Comfort dependency.
- **B-full:** the registered canonical composition — default Comfort
  startup, `(repl)` owns `lisp65>`, native C fallback visibly marked.
  Requires the Comfort return (Block C) to be accepted first.

Either variant closes the new cursor Known Issue. B-light is the safe
release carrier; B-full may supersede it within the same cycle if C
lands.

## Block B r5 placement price — 2026-08-29

The r4 non-inline boundary worked, but its final LTO map exposed the cost that
the micro-prototype omitted.  The host-only successor price corrects the

32-byte ordinary-text floor must survive after the overlap is gone.

Exactly one candidate is recommended.  The existing 98-byte mapped Far facade
moves inside its already-owned `$B3B0..$B4A3` arena.  Its VMA is derived as
`max(arena_start, final_text_end + 32)`, and its LMA follows the unchanged

No WPLTO or link ran.  A fourth link remains an owner decision.  If opened, r5

## Block B first device red and bounded repair — 2026-08-29

The first bundled contact stopped before accepting any Block-A or Block-B
row.  The stopped-state capture named a deterministic display mechanism:
`%native-prompt` sent HOME (`$13`) and twenty-four DOWN (`$11`) bytes through
`write-char`, while the delivered `LISP65_SCREEN_DRIVER` treats both bytes as
ordinary blank cells and advances its sequential cursor.  The prompt therefore
began on row 9 at column 25; the editor independently drew its cursor through
direct cells on row 24 at column 8.  The old host fixture false-greened because
it modeled the KERNAL mnemonics rather than the delivered driver's behavior.

The one bounded daily-use repair round is open.  Its law is: **prompt and
input share one editor-owned row; no KERNAL control code positions that row.**
The permanent general rule is: **a surface has exactly one positioning model;
control codes are positioning only when the delivered driver interprets them
as positioning.**  The successor gate models all 2,000 cells of the delivered
80x25 surface, rejects the captured row-9/row-24 split as a mutation, and keeps
explicit `(read-line)` framebuffer-identical.

The source transform is Bank-2-only and byte-neutral in aggregate (the shared
tail helper grows by eleven bytes while `%native-prompt` shrinks by eleven),
but it changes the generated stdlib literal inventory and product build
identity consumed by native code.  Therefore the already authorized r7
WPLTO/product link is required after a zero-link preflight; it is not an
artifact-only rewrite.  Any red in that sole round descopes B-light and leaves
Block A as the v1.9 carrier.  A green successor session repeats every A+B row,
because the stopped contact accepted none of them.

## Reviewer ruling — Block A consumer-side red, one repair round — 2026-08-28

The follow-up row read `raw/seen/stored/taken = 2/2/2/0`: capture arms
and stores, but the delivered editor still consumes the public hardware
queue, so the ring's contents are never taken. Losslessness has no device
basis and the v1.5 Known Issue stays open.

The gate gap is the reviewer's: the armed-lifecycle preflight was bound
to prove that the ring *arms* on the delivered `read-line` path, not that
it *is the editor's source*. The host wall (94 produced / 94 captured /
94 drained) therefore exercised a consumer the delivered world does not
use — the fifth shape of "host-green was false" after ASCII fixtures,
synthetic profiles, CALLPRIM-12 and the publication boundary.

**Authorized: one bounded repair round for Block A** (its first), with
one WPLTO and one product link if product bytes are needed:

1. Wire the take side: the delivered editor's key source is the ring
   while armed; the public queue path stays the disarmed-world fallback
   and the single-owner contract is unchanged.
2. **Gate extended, and this is the acceptance condition:** the pre-media
   preflight proves *consumption* at the final ELF — the editor's key
   source resolves to the ring take, and a mutation that leaves the queue
   as the source must fall. Arming alone is no longer sufficient.
3. The host wall is rebuilt against the delivered consumer, not a
   fixture-local one; a wall that passes while `taken` stays zero is
   itself a red.
4. Device re-verification is the same short counter row:
   `raw = seen = stored = taken`, non-zero.

If the round does not land green, Block A descopes and **v1.9.0 ships on
