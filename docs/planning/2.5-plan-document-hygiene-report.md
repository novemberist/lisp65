## Census

The commission's estimate of 197 planning documents had aged while the v1.9
release and the v2.0 cutting surface landed. The measured pre-change Git tree
at the start of this conversion contained **209** tracked Markdown planning
documents. This block adds three classified documents — the runtime report,
the v1.8 cycle root and this report — for a final census of **212**. Every one
has exactly one `config/document-index.json` row; no indexed planning path is
absent from the tree.

The sweep found no second live v1.6/v1.7 cycle root and no planning document
that required deletion or evidence relocation. Reports and receipts remain in
their existing classes because they are evidence about a cycle, not competing
cycle authorities. Three historical consumers still treated the live v1.7
path as their old world: the v1.6 housekeeping closure and two v1.8 media/
D-session checkers. The first two inner-loop runs exposed that era crossing.
They now reconstruct the relevant status, index and decision sections from
their sealing commits and reject the shortened live root or relocated path as
substitutes for sealed provenance. The correction is otherwise deliberately
limited to the four cycle roots and their successor metadata.

The first two non-certifying inner-loop passes stopped on those historical
consumers, one era boundary at a time. After all three conversions, the same
living graph completed with Exit 0. This makes the migration audit itself a
find-first-difference proof: no additional plan-path consumer remained behind
the three named members.

## Permanent enforcement

`tools/host-lisp/plan_document_hygiene.py` reads the old v1.7 tail from its
sealing commit, verifies its hash and requires exact byte identity inside the
new verbatim boundaries. It rejects a duplicated old tail, a changed moved
byte, a missing v1.6 seal, a missing v1.9 provenance link, a broken successor
chain, or an unclassified planning document. Six mutations exercise those
failures.

The gate is a member of complete `check-source` and of the non-certifying
inner loop. It checks; it never rewrites. The one-shot `apply` mode is guarded
to the exact pre-move source world and cannot silently re-run over a successor.
