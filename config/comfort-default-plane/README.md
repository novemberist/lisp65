# Comfort default plane and medium authority (pending)

`plane.json` inherits the unchanged consumed 2.4.0 Bank-2 resident plane.
`libraries/` binds the five existing packages, the v250 Comfort successor,
and INIT's deferred start request. The library source version changes;
its public package name stays `repl-comfort` and shelf label stays `repl`.

`media-authority.json` describes a host pack dry-run with the OLD runtime.
It is not a product candidate. All six package artifacts and index seals
are rebuilt and decoded, including the unchanged five artifacts.
A future accepted product must regenerate all build-id and boot-role CRC
bindings. Nothing here authorizes Seed, Final, link, emulator or device work.
